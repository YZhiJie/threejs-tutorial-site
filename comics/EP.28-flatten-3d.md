## 知识点拆解

### ① 面数救不了风格：NPR 是"读图说明书"

写实渲染靠光影、遮挡、景深把物体分开；一旦光照被压平，颜色相近的物体就会粘成一片。描边不是装饰，而是告诉观众"这里是轮廓、那里是独立物件"的说明书。**所以 NPR 的第一课不是加细节，而是加边界与分级**：少一点连续过渡，多一点明确色块。面数只影响轮廓的圆滑程度，不会自动产生"画"的感觉。

### ② 光照分级：把连续函数切成台阶

Lambert 的 `ndl` 是 0 到 1 的连续值，卡通渲染把它映射到有限的几档：

| 路径 | 做法 | 特点 |
| --- | --- | --- |
| step 函数 | `floor(ndl * n) / n` | 无需贴图，档数由 uniform 控制 |
| ramp 贴图 | 采样 256×1 的渐变图 | 边界、颜色、软硬都能由美术调 |

```glsl
vec3 ramp = texture2D(uRamp, vec2(ndl, 0.5)).rgb;
vec3 col = uBase * ramp;
col += uShadowTint * (1.0 - ramp.r) * 0.20;
```

ramp 用 RGB 三通道，暗部偏蓝、亮部偏暖，分级与调色一次完成。3 档是主流：亮、中间、暗刚好够读出体积；2 档更像海报，5 档更接近厚涂。高光也要用 `step` 切块，暗部则必须带一点冷色，纯灰会让画面"灰死"。

### ③ 四条描边路线：先分清外轮廓与内部线

| 做法 | 成本 | 能画到的线 |
| --- | --- | --- |
| 反向外壳 | 每物体 +1 draw call | 只有外轮廓 |
| 后处理边缘 | 预渲染 + 1~2 个全屏 Pass | 内外线都有 |
| 菲涅尔 | 零额外绘制 | 只有轮廓，随视角变 |
| 纹理描边 | 每像素 +4 次采样 | 内部结构线强，外轮廓弱 |

反向外壳的关键是**在裁剪空间外扩**：`clip.xy += nView.xy * widthPx * 2.0 / resolution * clip.w`，用 `clip.w` 抵消透视的近大远小，线宽才稳定。后处理描边要先渲染法线与深度，再做 Sobel；深度要线性化，法线要 `* 2.0 - 1.0` 解码。菲涅尔是"用亮度差模拟轮廓"，最便宜但也最不稳定。纹理描边靠 UV 外扩比较法线差，能画出衣领、褶皱这类内部线。

### ④ 组装管线：三种模式，五件事一起切

一条完整的水墨管线是：几何渲染 → 辅助缓冲（可选）→ 描边 → 去色与色阶 → 噪声阈值 → 纸纹与笔触 → 输出。两个铁律：**描边必须在量化之前**（否则色块边界会被误判成线）；**整条链只做一次色调映射**（统一交给 `OutputPass`）。

模式切换要同步改五件事：`mesh.material`、`renderer.toneMapping`、`scene.background`、`scene.fog`、`inkPass.enabled`。少改一项就会出现"水墨模式里还挂着写实暖雾"的违和。水墨的墨色分层用带噪声的窄区间 `smoothstep`，噪声不是叠在画面上，而是决定"这个像素算哪一档"，所以边界会自然长出毛边。

## 坑点清单（FAQ）

- **Q：卡通渲染暗部发灰发脏？** 多半是软阴影的连续灰带混进了色阶，或暗部只做了变暗没加冷色。改硬边阴影，暗部叠 0.1~0.25 的冷色偏移。
- **Q：外壳描边近粗远细？** 用了世界单位外扩。改裁剪空间公式并乘 `clip.w`，resize 时同步 `uResolution` 与 `devicePixelRatio`。
- **Q：后处理描边满屏短线与噪点？** 检查深度精度、法线是否解码、搜索半径是否只有一像素；半径提到 2~3 像素并加阈值余量。
- **Q：风格化后边缘一直闪？** 单采样边缘检测 + 一像素线宽是主因；配 SMAA、加粗线宽、远处淡出。噪声必须连续，禁止每帧 `Math.random()`。
- **Q：切换模式卡一下？** shader 重编译。三份材质提前创建、切换只换引用，或用 `compileAsync` 预编译。

## 自测（Quiz）

1. 反向外壳、后处理边缘、菲涅尔、纹理描边，各自能画外轮廓还是内部线？成本分别是什么？
2. 为什么卡通渲染里软阴影反而让画面"脏"？应该怎么处理暗部？
3. 水墨管线的正确顺序是什么？为什么描边必须放在量化之前？

<details>
<summary>答案</summary>

1. 反向外壳只能画外轮廓，每物体多一次 draw call；后处理边缘内外线都能画，需要一次法线/深度预渲染加一至两次全屏 Pass；菲涅尔只能画外轮廓，零额外绘制，但线宽随视角变化；纹理描边擅长内部结构线，每像素多四次纹理采样，但描不到真正的物体外轮廓，通常与外壳搭配。
2. 软阴影在亮部与暗部之间制造了一条连续灰带，这条灰带既不属于亮色阶也不属于暗色阶，视觉上就是"脏"。处理方式是改硬边阴影、减小模糊半径、去掉会撒灰的 SSAO，并给暗部叠加 0.1~0.25 的冷色偏移，避免纯灰。
3. 顺序是：几何渲染 → 辅助缓冲（可选）→ 描边 → 去色与色阶 → 噪声阈值 → 纸纹与笔触 → 输出。描边必须在量化之前，因为量化会产生大量色块边界，边缘检测会把它们全部误判成线，结果是满屏墨；应在颜色还连续时找边，再把线压上去。
</details>
