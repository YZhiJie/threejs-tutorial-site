精通方向扩展任务文档 ​

版本：v1.0 · 创建日期：2026-10-31 前置阅读：learning-path.md（现有 11 模块 × 3 阶段体系）

1. 背景与目标 ​

1.1 现状 ​

现有教程覆盖模块 ①–⑪（认识 → 场景 → 相机 → 渲染器 → 几何体 → 材质 → 纹理 → 灯光 → 动画 → 交互 → 综合实战），解决"会用"的问题，出口能力是"可交互的 3D 小作品"。

1.2 扩展目标 ​

新增模块 ⑫–㉓（共 12 个），整套教程升级为 23 模块 × 4 阶段，使零基础起步的学员学完后能够：

  • 用 GLSL / 后处理实现企业级自定义视觉效果（扫描线、全息、溶解、热力等）；
  • 对接真实美术资产（glTF 压缩管线、骨骼动画）；
  • 扛起大规模场景（Instancing / LOD / BVH / 流式加载）；
  • 按企业工程标准落地（框架集成、性能预算、测试监控）；
  • 交付行业场景作品（可视化大屏 / 数字孪生 / WebXR / 物理仿真）。

1.3 能力缺口 → 模块映射 ​

缺口对应模块
不能定制视觉⑫ 自定义着色器 → ⑬ 后处理管线 → ⑭ 高级光照与 IBL
接不了真实资产⑮ glTF 资产管线
扛不住场景规模⑯ 大场景组织与优化 → ⑰ 粒子与 GPU 计算
落不了工程地⑱ R3F 集成 → ⑲ 工程化与性能体系 → ⑳ 测试与质量保障
缺行业模板㉑ 大屏与数字孪生 → ㉒ WebXR → ㉓ 物理仿真游戏化

2. 全局设计约束（所有任务必须遵守） ​

编号约束
C1每章沿用四段式固定结构：核心概念讲解 → 代码示例（逐段中文注释）→ 运行效果展示（DemoFrame 内嵌演示）→ 常见问题解答（FAQ）
C2每模块固定三篇：basics.md（基础入门）/ advanced.md（进阶应用）/ practice.md（实战案例），标题格式 N.1 基础入门：xxx
C3每模块配 1 期漫画剧场 EP（comics/EP.NN-<slug>.md + 同名 .svg），登记进 comics/manifest.json，并通过 node comics/check-comics.mjs 校验
C4演示全部可运行，放在 public/demos/<主题>/*.html；iframe 预览 / 复制源码 / 新窗口打开三个功能必须使用 withBase 处理部署前缀（/threejs-tutorial-site/），禁止硬编码路径

4. 批次计划 ​

执行规则（与既定工作流一致）：

  1. 按批次优先级顺序依次执行，批次内任务按编号顺序推进；除非遇到 §8 的关键决策点，否则中间不停顿。

  3. 批次内所有任务完成后，统一运行 §7 全量门禁检查，全部通过方可进入下一批次。
