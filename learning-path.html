学习路径建议 ​

Three.js 的知识点看似庞杂，但只要遵循"先搭骨架，再长血肉"的顺序，学习曲线可以非常平滑。本教程把内容组织为 39 个模块 × 6 个阶段（其中 ㉛㉜ 为前瞻内容，不计入考核），并给出推荐的学习节奏与自测标准。

六个阶段分别学什么 ​

基础 建立概念，能跑通最小示例进阶 理解原理，掌握可调参数实战 组合知识，完成小作品
  • 基础入门：回答"它是什么、什么时候用"，每个概念配一个 20 行左右的最小示例。
  • 进阶应用：回答"参数怎么调、底层怎么运作"，引入多个对象之间的协作关系。
  • 实战案例：回答"怎么组合起来做东西"，每章产出一个可交互的小案例。

推荐学习顺序（四周计划） ​

下表给出建议顺序、依赖关系与检验标准。每天投入 45–60 分钟，约四周可完成全部内容。

周次模块为什么是这个顺序学完的检验标准
第 1 周① 认识 → ② 场景 → ③ 相机 → ④ 渲染器先打通"场景→相机→渲染器→画面"这条最小管线，这是所有 Three.js 程序的骨架不看教程能手写一个旋转立方体页面
第 2 周⑤ 几何体 → ⑥ 材质 → ⑦ 纹理解决"画面里放什么、它长什么样"，三者共同决定物体外观能为物体贴上自制图案并解释 UV 是什么
第 3 周⑧ 灯光 → ⑨ 动画先让静态场景有明暗质感，再让它动起来，符合观察习惯能做出带阴影、可循环播放的关键帧动画
第 4 周⑩ 交互 → ⑪ 综合实战最后处理用户输入，把前面所有模块组装成完整作品完成一个可旋转、可点击的 3D 场景小作品

精通方向扩展（阶段二～六） ​

完成阶段一（①–⑪）后，你已经"会用"Three.js。精通方向的扩展模块从 ⑫ 起按阶段持续扩充，目标是把能力提升到企业级复杂场景：

  • 阶段二 · 视觉与资产核心能力（⑫–⑰）：自定义着色器、后处理管线、高级光照 IBL、glTF 资产管线、大场景优化、粒子与 GPU 计算。学完后能独立实现定制特效、接入真实美术资产、扛起万级实例场景。建议节奏约 6 周。
  • 阶段三 · 工程化体系（⑱–⑳）：React Three Fiber 集成、工程化与性能体系、测试与质量保障。学完后能按企业工程标准落地 3D 项目。建议节奏约 3 周。
  • 阶段四 · 行业场景实战（㉑–㉓）：可视化大屏与数字孪生、WebXR、物理仿真与游戏化。学完后能交付行业场景综合作品。建议节奏约 3 周。
  • 阶段五 · 精通闭环（㉔–㉜）：色彩管理与图形学原理、线上监控与容错、GPU 性能治理、材质着色器进阶与 NPR 风格化、程序化建模、3D 数据可视化，以及 WebGPU/TSL 前瞻。学完后能解释"画面为什么是这样"、在上线环境里自证健康，并具备下一代渲染 API 的迁移能力。
  • 阶段六 · 行业纵深（㉝–㊳）：跨端与框架广度、GIS 深度、场景编辑器与配置化平台、数字人、游戏化与交互系统。学完后能承担行业项目的架构与落地。

节奏建议与阶段一相同：每天投入 45–60 分钟，先跑通演示再改参数。每个扩展模块同样按"基础入门 → 进阶应用 → 实战案例"三篇组织，并在开篇用已学模块的旧案例"接桥"过渡。

给不同读者的建议 ​

  • 零基础读者：先完成 0 学前必备的自查清单，确认 JavaScript 与运行环境两块硬性门槛过关，再严格按顺序学习，每个"基础入门"后的小练习务必亲手敲一遍，不要只复制粘贴。
  • 有其他 3D 引擎经验（Unity / Unreal）的读者：可快速浏览①–④建立 API 映射，重点阅读⑤–⑧中"与传统引擎的差异"部分。
  • 有一定 Three.js 基础的读者：建议从各模块的"进阶应用"切入，用"实战案例"检验掌握程度，遇到盲点再回跳基础篇。
  • 目标企业级场景的读者：完成 ①–⑪ 后，按"精通方向扩展"的阶段二～四继续推进，最终交付可定制特效、真实资产、工程化落地的行业级作品。

学习方法提示 ​

  1. 先跑起来再改：打开内嵌演示 → 点"在线编辑" → 每次只改一个参数，观察画面变化。
  2. 用搜索建立索引：顶部搜索框支持全文检索，遇到具体问题（如"阴影锯齿"）直接搜关键词。
  3. 善用 FAQ：每章末尾的常见问题覆盖了初学者 80% 的报错场景，卡住时先查它。
  4. 画自己的管线图：每学完一个模块，尝试默写出它在渲染管线中的位置（本教程的 Diagram 示例可作为起点）。
