6.1 基础入门：四种常用材质对比 ​

核心概念讲解 ​

材质决定物体"怎么与光互动、最终呈现什么颜色"。Three.js 有十几个材质类，初学者先掌握下面四种就能覆盖绝大多数场景：

材质受灯光影响特点典型用途
MeshBasicMaterial❌ 完全不直接显示纯色/贴图，无明暗天空盒、UI、发光体、线框
MeshLambertMaterial✅只有漫反射，无高光，性能最好低多边形、墙面、远景
MeshPhongMaterial✅漫反射 + 可调锐利高光（shininess）光泽塑料、老式 PBR 前方案
MeshStandardMaterial✅基于物理（PBR），用 roughness/metalness 描述现代项目默认选择

术语解释：

  • 漫反射（Diffuse）：光线打到粗糙表面后向四面八方均匀弹开，表现为"哑光"颜色。
  • 高光（Specular）：光滑表面把光朝特定方向反射形成的亮斑。
  • PBR（Physically Based Rendering）：基于物理的渲染，用粗糙度/金属度等物理量描述材质，在任何光照下都更真实一致。

为什么 StandardMaterial 是默认选择 ​

它只有两个核心旋钮：

  • roughness（粗糙度）：0 = 镜面，1 = 完全粗糙
  • metalness（金属度）：0 = 非金属（塑料/木材），1 = 纯金属

这两个量符合直觉、能量守恒、跨光照环境稳定，是 glTF 等行业标准采用的模型。

代码示例 ​

让四种材质在同一束旋转光、同一个环结形状上并排对比：

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import GUI from 'three/addons/libs/lil-gui.module.min.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0b0e14)
const camera = new THREE.PerspectiveCamera(45, innerWidth / innerHeight, 0.1, 100)
camera.position.set(0, 2.4, 7.5)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
document.getElementById('app').appendChild(renderer.domElement)
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true
controls.target.set(0, 0.4, 0)

// 极弱环境光，突出方向光差异
scene.add(new THREE.AmbientLight(0xffffff, 0.15))
const sun = new THREE.DirectionalLight(0xffffff, 2.2)
sun.position.set(0, 4, 4)
scene.add(sun)

// 光源位置标记
const marker = new THREE.Mesh(
  new THREE.SphereGeometry(0.14, 16, 12),
  new THREE.MeshBasicMaterial({ color: 0xfff7cc })
)
scene.add(marker)
scene.add(new THREE.GridHelper(12, 12, 0x334155, 0x1e293b))

const columns = [
  ['MeshBasicMaterial',    () => new THREE.MeshBasicMaterial({ color: 0x4f9cf9 })],
  ['MeshLambertMaterial',  () => new THREE.MeshLambertMaterial({ color: 0x4f9cf9 })],
  ['MeshPhongMaterial',    () => new THREE.MeshPhongMaterial({
    color: 0x4f9cf9, shininess: 90, specular: 0xffffff })],
  ['MeshStandardMaterial', () => new THREE.MeshStandardMaterial({
    color: 0x4f9cf9, roughness: 0.35, metalness: 0.1 })]
]

const knots = columns.map(([name, make], i) => {
  const knot = new THREE.Mesh(new THREE.TorusKnotGeometry(0.62, 0.2, 160, 24), make())
  knot.position.set((i - 1.5) * 2.6, 0.9, 0)
  scene.add(knot)
  return knot
})

const params = { lightOrbit: true, lightSpeed: 0.8, lightHeight: 4 }
const gui = new GUI({ title: '灯光' })
gui.add(params, 'lightOrbit').name('光源旋转')
gui.add(params, 'lightSpeed', 0, 3, 0.05)
gui.add(params, 'lightHeight', 1, 8, 0.1)

const clock = new THREE.Timer()

clock.connect(document) // r183 起 Clock 已弃用，改用 Timer
renderer.setAnimationLoop(() => {
  clock.update() // 每帧先 update，再读取
  const t = clock.getElapsed()
  if (params.lightOrbit) {
    const a = t * params.lightSpeed
    sun.position.set(Math.cos(a) * 4.5, params.lightHeight, Math.sin(a) * 4.5)
  }
  marker.position.copy(sun.position)
  knots.forEach(k => { k.rotation.y += 0.006; k.rotation.x += 0.003 })
  controls.update()
  renderer.render(scene, camera)
})

常见问题解答 ​

Q1：Basic 材质是不是"最差"，所以实际不用？

不是。它在"本来就不该受光"的地方非常常用：纯 UI 面板、星空背景、发光灯条、调试包围盒。用对地方它反而是最便宜正确的选择。

Q2：Phong 的 shininess 和 Standard 的 roughness 是一回事吗？

方向相反且模型不同：shininess 越大高光越集中（锐利），roughness 越小越光滑。但 Phong 不是物理模型，调到极端时容易不真实；新项目建议直接用 Standard 的 roughness。

Q3：为什么我的 Standard 材质看起来总是灰蒙蒙？

Standard 依赖环境反射。没有任何环境贴图时，roughness 高的表面缺少反射内容就显得灰。用 RoomEnvironment 给 scene.environment 一张环境贴图（下一篇会讲），质感立刻提升。

动手小练习 ​

  1. 把环境光完全关掉、只留方向光，观察 Lambert 与 Standard 暗部的差异。
  2. 把 Phong 的 shininess 从 1 调到 200，看高光斑从一大团缩成一个点。
  3. 把四个材质都换成同一个颜色值，确认"差异完全来自光照模型而非颜色"。
