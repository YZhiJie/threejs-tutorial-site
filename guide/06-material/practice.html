6.3 实战案例：材质参数实验室 ​

核心概念讲解 ​

学材质最快的方式不是背参数表，而是搭一个能实时调所有参数的实验室，把抽象数值和肉眼观感建立对应。本篇把 StandardMaterial 的常用开关全部接到 lil-gui，再配合环境贴图一次看清。

本篇要实验的参数分组 ​

  • 颜色与反射：color、roughness、metalness、envMapIntensity
  • 着色方式：flatShading（平面着色）、wireframe
  • 透明：transparent + opacity + side（正反面）
  • 自发光：emissive + emissiveIntensity（发光但不照亮别人）

改 side / transparent 后要 needsUpdate ​

side（FrontSide/BackSide/DoubleSide）和是否透明会影响材质的渲染顺序与着色器变体，改完需：

js
material.needsUpdate = true

而 roughness/color/opacity 这类标量则不需要。

代码示例 ​

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import { RoomEnvironment } from 'three/addons/environments/RoomEnvironment.js'
import GUI from 'three/addons/libs/lil-gui.module.min.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0b0e14)
const camera = new THREE.PerspectiveCamera(45, innerWidth / innerHeight, 0.1, 100)
camera.position.set(0, 1.6, 4.6)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
document.getElementById('app').appendChild(renderer.domElement)
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true

// 有环境贴图，调金属度/粗糙度才有反射内容可看
const pmrem = new THREE.PMREMGenerator(renderer)
scene.environment = pmrem.fromScene(new RoomEnvironment(), 0.04).texture

const ground = new THREE.Mesh(
  new THREE.CircleGeometry(6, 48),
  new THREE.MeshStandardMaterial({ color: 0x1c2330, roughness: 0.9 })
)
ground.rotation.x = -Math.PI / 2
ground.position.y = -1.05
scene.add(ground)

const material = new THREE.MeshStandardMaterial({
  color: 0x4f9cf9,
  roughness: 0.5,
  metalness: 0.1,
  side: THREE.FrontSide
})
const ball = new THREE.Mesh(new THREE.SphereGeometry(1, 64, 48), material)
scene.add(ball)

// 外接线框二十面体，旋转时帮助感知球体朝向
const wire = new THREE.Mesh(
  new THREE.IcosahedronGeometry(1.35, 1),
  new THREE.MeshBasicMaterial({ color: 0x334155, wireframe: true, transparent: true, opacity: 0.4 })
)
scene.add(wire)

const params = {
  color: '#4f9cf9', roughness: 0.5, metalness: 0.1,
  flatShading: false, wireframe: false,
  transparent: false, opacity: 1, side: 'FrontSide',
  emissive: '#000000', emissiveIntensity: 1,
  envMapIntensity: 1, spin: true
}
const gui = new GUI({ title: '材质实验室' })
gui.addColor(params, 'color').name('颜色').onChange(v => material.color.set(v))
gui.add(params, 'roughness', 0, 1, 0.01).onChange(v => material.roughness = v)
gui.add(params, 'metalness', 0, 1, 0.01).onChange(v => material.metalness = v)
gui.add(params, 'flatShading').name('平面着色').onChange(v => material.flatShading = v)
gui.add(params, 'wireframe').name('线框').onChange(v => material.wireframe = v)
gui.add(params, 'transparent').name('透明开关').onChange(v => material.transparent = v)
gui.add(params, 'opacity', 0, 1, 0.01).name('不透明度').onChange(v => material.opacity = v)
gui.add(params, 'side', ['FrontSide', 'BackSide', 'DoubleSide']).name('渲染面')
  .onChange(v => material.side = THREE[v])
gui.addColor(params, 'emissive').name('自发光色').onChange(v => material.emissive.set(v))
gui.add(params, 'emissiveIntensity', 0, 3, 0.05).name('自发光强度')
  .onChange(v => material.emissiveIntensity = v)
gui.add(params, 'envMapIntensity', 0, 3, 0.05).name('环境反射').onChange(v => material.envMapIntensity = v)
gui.add(params, 'spin').name('自转')
// side / transparent / flatShading 等影响着色器变体的改动统一刷新
gui.onChange(() => material.needsUpdate = true)

renderer.setAnimationLoop(() => {
  if (params.spin) {
    ball.rotation.y += 0.006
    wire.rotation.y -= 0.004
  }
  controls.update()
  renderer.render(scene, camera)
})

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight
  camera.updateProjectionMatrix()
  renderer.setSize(innerWidth, innerHeight)
})

常见问题解答 ​

Q1：开了 transparent 又把 opacity 调到很低，为什么边缘还是有黑圈？

透明物体有渲染顺序问题，且不透明的"边缘描边感"来自背景没透过。确认场景背景不是纯黑、物体后面有东西可透过；必要时把材质 depthWrite 按场景需求调整（复杂透明排序问题通常需要人工安排 renderOrder）。

Q2：emissive 设得很亮，为什么周围物体没被照亮？

自发光只影响这个材质自己的输出颜色，不会向场景发射光线。要让它真正照明，需要在该位置放一盏真实的灯（PointLight/RectAreaLight），或使用较新的光照探针/GI 方案。

Q3：BackSide 和 DoubleSide 什么时候用？

BackSide 只渲染背面，常用于"灯罩、云朵内层、房间内景（盒内朝外）"；DoubleSide 两面都渲染，适合布料、玻璃、叶片这种没有厚度的单面几何体，代价是略增绘制。

动手小练习 ​

  1. 调出一个"拉丝金属"：metalness=1、roughness=0.35、envMapIntensity=1.6，再换偏灰颜色。
  2. 调出"霓虹灯"：颜色调黑、emissive 设青色、emissiveIntensity=2.5。
  3. 用 transparent + opacity=0.4 + DoubleSide 做一块毛玻璃片，与实体球叠放观察透视。
