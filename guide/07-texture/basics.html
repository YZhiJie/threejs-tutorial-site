7.1 基础入门：纹理贴图与 CanvasTexture ​

核心概念讲解 ​

什么是纹理（Texture） ​

纹理就是一张贴到几何体表面的 2D 图片。几何体每个顶点都带 UV 坐标，告诉 GPU"这个点对应图片上的哪个位置"，GPU 在三角形内部做插值，把图像"裹"到 3D 表面上。

术语解释：

  • UV：纹理坐标，u 对应图片横向、v 对应纵向，范围通常 0~1，原点在左下角。
  • 采样（Sampling）：GPU 根据 UV 从图片读取颜色的过程。

纹理的常见类型 ​

Three.js 里一张图可以塞进材质的不同"槽位"，承担不同物理职责：

  • map：基础颜色贴图（最常用）
  • roughnessMap / metalnessMap：粗糙度 / 金属度贴图
  • normalMap：法线贴图，用一张图伪造表面凹凸细节（不增加三角形）
  • emissiveMap：自发光贴图
  • aoMap：环境光遮蔽贴图，角落变暗增强层次

没有图片文件怎么办：CanvasTexture ​

你可以用 <canvas> 动态画一张图，再 new THREE.CanvasTexture(canvas) 交给 Three.js。好处：零外部资源、可程序化、能实时重绘，做标签、棋盘、雷达图、噪声都非常方便。

r186 必须注意的色彩空间 ​

颜色类贴图（map/emissiveMap）要标记为 sRGB，否则颜色会发暗/发灰：

js
texture.colorSpace = THREE.SRGBColorSpace

数据类贴图（normalMap/roughnessMap）保持线性，不要设 sRGB。

代码示例 ​

用 Canvas 程序化画一张棋盘+数字格子贴图，贴到立方体和平面上：

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import GUI from 'three/addons/libs/lil-gui.module.min.js'

// 程序化生成一张 512×512 的棋盘格 Canvas，格子里写编号
function makeCheckerCanvas(grid = 8) {
  const cv = document.createElement('canvas')
  cv.width = cv.height = 512
  const ctx = cv.getContext('2d')
  const cell = cv.width / grid
  for (let y = 0; y < grid; y++) {
    for (let x = 0; x < grid; x++) {
      ctx.fillStyle = (x + y) % 2 ? '#f8fafc' : '#0f172a'
      ctx.fillRect(x * cell, y * cell, cell, cell)
      ctx.fillStyle = (x + y) % 2 ? '#0f172a' : '#f8fafc'
      ctx.font = `${cell * 0.36}px sans-serif`
      ctx.textAlign = 'center'
      ctx.textBaseline = 'middle'
      ctx.fillText(`${x},${y}`, x * cell + cell / 2, y * cell + cell / 2)
    }
  }
  return cv
}

const canvas = makeCheckerCanvas(8)
const texture = new THREE.CanvasTexture(canvas)
texture.colorSpace = THREE.SRGBColorSpace      // 颜色贴图标记 sRGB
texture.anisotropy = 8                          // 各向异性过滤：斜视时更清晰

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0b0e14)
const camera = new THREE.PerspectiveCamera(45, innerWidth / innerHeight, 0.1, 100)
camera.position.set(0, 1.8, 4.6)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
document.getElementById('app').appendChild(renderer.domElement)
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true

scene.add(new THREE.HemisphereLight(0xbfd9ff, 0x202020, 0.9))
const dir = new THREE.DirectionalLight(0xffffff, 1.8)
dir.position.set(3, 5, 4)
scene.add(dir)

// 同一个纹理对象可被多个材质/网格共享
const mat = new THREE.MeshStandardMaterial({ map: texture, roughness: 0.6 })
const cube = new THREE.Mesh(new THREE.BoxGeometry(1.6, 1.6, 1.6), mat)
cube.position.set(-1.5, 0.8, 0)

// 平面用 DoubleSide，方便从地面角度观察 UV 方向
const plane = new THREE.Mesh(
  new THREE.PlaneGeometry(2.2, 2.2),
  new THREE.MeshStandardMaterial({ map: texture, side: THREE.DoubleSide, roughness: 0.7 })
)
plane.rotation.x = -Math.PI / 2
plane.position.set(1.5, 0, 0.3)
scene.add(cube, plane)

const params = { anisotropy: 8, flipY: true }
const gui = new GUI({ title: '纹理' })
gui.add(params, 'anisotropy', [1, 2, 4, 8, 16]).name('各向异性').onChange(v => {
  texture.anisotropy = v
  texture.needsUpdate = true
})
gui.add(params, 'flipY').name('flipY 上下翻转').onChange(v => {
  texture.flipY = v
  texture.needsUpdate = true
})

renderer.setAnimationLoop(() => {
  cube.rotation.y += 0.006
  controls.update()
  renderer.render(scene, camera)
})

常见问题解答 ​

Q1：贴上去的图颜色为什么比原图暗/灰？

颜色贴图没设 colorSpace = SRGBColorSpace。r152 起 Three.js 色彩管理默认开启，颜色类贴图必须标记 sRGB，法线/粗糙度等数据贴图保持线性。

Q2：斜着看贴图为什么一片模糊/摩尔纹？

提高 texture.anisotropy（各向异性过滤等级，最大可取 renderer.capabilities.getMaxAnisotropy()）。它让表面与视线夹角很小时仍沿斜向清晰采样。

Q3：CanvasTexture 改了 canvas 内容为什么画面不更新？

重绘 canvas 后设 texture.needsUpdate = true，Three.js 才会重新上传。注意频繁整图重绘有开销，可只在内容真正变化时触发。

动手小练习 ​

  1. 把棋盘格改成渐变 + 网格线，体会 Canvas 2D API 都能成为纹理来源。
  2. 给立方体的每个面不同 UV（用 BoxGeometry 已有的 UV 缩放：设置 texture.repeat.set(2,2)）。
  3. 用一张 CanvasTexture 同时作为 map 和 emissiveMap，观察自发光区域如何跟随图案。
