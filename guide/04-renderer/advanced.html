4.2 进阶应用：画质、像素比与色调映射 ​

核心概念讲解 ​

影响画质的四个开关 ​

设置作用代价
antialias: true多重采样抗锯齿，消除边缘楼梯感上下文级参数，不可热切换
setPixelRatio(n)匹配高分屏物理像素，画面更清晰像素填充量随 n² 增长
shadowMap.type阴影过滤算法：Basic / PCF / VSM（r186 已移除 PCFSoft）类型本身几乎无差，VSM 需额外模糊 pass
toneMapping把 HDR 亮度压缩到屏幕范围极低

抗锯齿为什么不能运行时切换 ​

antialias 是创建 WebGL 上下文 时申请的能力（sample buffer 数量），上下文一旦建立就不能改。要切换只能销毁重建 renderer（示例演示了完整流程）。如果需要运行时 AA，可改用后处理 FXAA / SMAA（EffectComposer 通道）。

色调映射 Tone Mapping ​

Three.js 灯光和材质内部可能产生大于 1 的亮度值（HDR），而屏幕只能显示 0~1。色调映射负责"压缩"：

  • NoToneMapping：直接截断，高光死白
  • ACESFilmicToneMapping：电影感，高光柔和过渡，最常用
  • ReinhardToneMapping：整体偏柔和、对比略低

toneMappingExposure 是曝光倍增器，像相机曝光补偿一样整体调亮/压暗。

术语解释：HDR（高动态范围） 允许亮度超过 1.0 参与光照计算，配合色调映射保留高光细节，避免亮部一片死白。

代码示例 ​

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import GUI from 'three/addons/libs/lil-gui.module.min.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0b0e14)
const camera = new THREE.PerspectiveCamera(45, innerWidth / innerHeight, 0.1, 100)
camera.position.set(0, 1.2, 5.5)

// renderer 用 let：切抗锯齿时要销毁重建
let renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
renderer.toneMapping = THREE.ACESFilmicToneMapping
renderer.toneMappingExposure = 1
document.getElementById('app').appendChild(renderer.domElement)

let controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true

// 高对比棋盘背景：锯齿/色带在这种图案上最容易看出
const checker = document.createElement('canvas')
checker.width = checker.height = 128
const cctx = checker.getContext('2d')
for (let y = 0; y < 8; y++) for (let x = 0; x < 8; x++) {
  cctx.fillStyle = (x + y) % 2 ? '#e5e7eb' : '#111827'
  cctx.fillRect(x * 16, y * 16, 16, 16)
}
const backdrop = new THREE.Mesh(
  new THREE.PlaneGeometry(9, 6),
  new THREE.MeshBasicMaterial({ map: new THREE.CanvasTexture(checker) })
)
backdrop.position.z = -2.2
scene.add(backdrop)

scene.add(new THREE.HemisphereLight(0xffffff, 0x333333, 0.5))
const strong = new THREE.DirectionalLight(0xffffff, 4)   // 强光制造 HDR 高光
strong.position.set(3, 5, 4)
scene.add(strong)

// 旋转红叶片看边缘锯齿；金属球看高光与色调映射
const blade = new THREE.Mesh(new THREE.BoxGeometry(3.2, 0.5, 0.06),
  new THREE.MeshStandardMaterial({ color: 0xef4444, roughness: 0.5 }))
blade.position.set(-0.4, 0.2, 0.4)
const metal = new THREE.Mesh(new THREE.SphereGeometry(0.75, 48, 32),
  new THREE.MeshStandardMaterial({ color: 0xffffff, metalness: 1, roughness: 0.15 }))
metal.position.set(1.5, -0.2, 1)
scene.add(blade, metal)

const params = {
  antialias: true,
  pixelRatio: Math.min(devicePixelRatio, 2),
  toneMapping: 'ACESFilmic',
  exposure: 1
}
const TONE = {
  None: THREE.NoToneMapping, Linear: THREE.LinearToneMapping,
  Reinhard: THREE.ReinhardToneMapping, Cineon: THREE.CineonToneMapping,
  ACESFilmic: THREE.ACESFilmicToneMapping
}
const gui = new GUI({ title: '画质参数' })
gui.add(params, 'antialias').name('antialias 抗锯齿').onChange(rebuild)
gui.add(params, 'pixelRatio', [0.5, 1, 1.5, 2]).name('pixelRatio').onChange(v =>
  renderer.setPixelRatio(v))
gui.add(params, 'toneMapping', Object.keys(TONE)).name('色调映射').onChange(v =>
  renderer.toneMapping = TONE[v])
gui.add(params, 'exposure', 0.1, 2.5, 0.05).name('曝光').onChange(v =>
  renderer.toneMappingExposure = v)

// 销毁旧 renderer 并用新参数重建（唯一能改 antialias 的方式）
function rebuild() {
  const oldCanvas = renderer.domElement
  controls.dispose()
  renderer.dispose()
  oldCanvas.remove()

  renderer = new THREE.WebGLRenderer({ antialias: params.antialias })
  renderer.setSize(innerWidth, innerHeight)
  renderer.setPixelRatio(params.pixelRatio)
  renderer.toneMapping = TONE[params.toneMapping]
  renderer.toneMappingExposure = params.exposure
  document.getElementById('app').appendChild(renderer.domElement)
  controls = new OrbitControls(camera, renderer.domElement)
  controls.enableDamping = true
}

renderer.setAnimationLoop(() => {
  blade.rotation.z += 0.012
  blade.rotation.x += 0.006
  controls.update()
  renderer.render(scene, camera)
})

常见问题解答 ​

Q1：手机上画面发烫、掉帧，先调什么？

先把 setPixelRatio 从 devicePixelRatio 降到 1，填充量立刻降到 1/4（2x 屏）；其次关阴影或降 mapSize；最后再考虑降几何体细分。像素比通常是移动端性价比最高的开关。

Q2：为什么开了 ACESFilmic 后颜色"变灰变淡"？

色调映射会压缩高光也会整体改变对比。配合 renderer.outputColorSpace = SRGBColorSpace（r152+ 默认已是）确保色彩空间正确，再用 exposure 找回亮度即可。

Q3：重建 renderer 后控制器为什么失灵？

旧 OrbitControls 绑定的是旧 canvas，旧 canvas 已移除。重建 renderer 时必须 controls.dispose() 解绑旧事件，再用新 canvas 新建一个控制器，如示例所示。

动手小练习 ​

  1. 对比 0.5 / 1 / 2 三档像素比下棋盘格的锐利程度与 FPS。
  2. 用强光 + 白色金属球，分别在五种 toneMapping 下截图对比高光过渡。
  3. 把 exposure 做成自动呼吸（0.6 ↔ 1.6 之间用 sin 缓动），观察画面像"亮度呼吸灯"。
