10.2 进阶应用：DragControls 拖拽变换 ​

核心概念讲解 ​

在 3D 空间里"拖动物体"的难点 ​

鼠标只有 2D，要在 3D 空间移动一个物体，必须定义"沿哪个平面拖"。DragControls 用 Raycaster 帮你处理了这件事：它默认在一个与相机视线垂直、过物体原点的平面上求交，把鼠标射线与该平面的交点作为新位置。

DragControls 与 OrbitControls 的冲突 ​

两者都监听 pointer 事件。当你在物体上按下想拖动时，OrbitControls 也会开始旋转相机，导致"边拖边转"。标准解法：开始拖拽时禁用 OrbitControls，结束时恢复：

js
dragControls.addEventListener('dragstart', () => controls.enabled = false)
dragControls.addEventListener('dragend',   () => controls.enabled = true)

术语解释：

  • 拖拽平面（drag plane）：把 2D 鼠标运动映射到 3D 的一个数学平面，默认由 DragControls 自动生成（面向相机）。
  • hoveron/hoveroff：DragControls 也提供悬停事件，可用于在可拖物体上显示 grab/grabbing 光标。

TransformControls：更精细的移动/旋转/缩放 ​

需要像编辑器那样沿指定轴精确变换时，用 TransformControls（带红绿蓝三个操纵杆 gizmo），而不是 DragControls 的自由平面拖动。

代码示例 ​

桌面上几个可拖物体 + 一个"回收区"，拖入区域变绿、松手可回收：

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import { DragControls } from 'three/addons/controls/DragControls.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0b0e14)
const camera = new THREE.PerspectiveCamera(45, innerWidth / innerHeight, 0.1, 100)
camera.position.set(0, 5, 7.5)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
document.getElementById('app').appendChild(renderer.domElement)
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true
controls.maxPolarAngle = Math.PI / 2 - 0.05
controls.target.set(0, 0.3, 0)

scene.add(new THREE.HemisphereLight(0xbfd9ff, 0x222222, 0.9))
const dir = new THREE.DirectionalLight(0xffffff, 1.8)
dir.position.set(3, 6, 4)
scene.add(dir)

const ground = new THREE.Mesh(
  new THREE.PlaneGeometry(14, 10),
  new THREE.MeshStandardMaterial({ color: 0x232b3a, roughness: 0.95 })
)
ground.rotation.x = -Math.PI / 2
scene.add(ground)

// 回收区：一个红色矩形区域，物体在其上方时变绿提示
const zone = new THREE.Mesh(
  new THREE.PlaneGeometry(3, 3),
  new THREE.MeshBasicMaterial({ color: 0xdc2626, transparent: true, opacity: 0.35 })
)
zone.rotation.x = -Math.PI / 2
zone.position.set(4.2, 0.01, 1.5)
scene.add(zone)

const objects = []
const geos = [
  new THREE.BoxGeometry(0.7, 0.7, 0.7),
  new THREE.SphereGeometry(0.42, 28, 20),
  new THREE.ConeGeometry(0.45, 0.9, 28),
  new THREE.CylinderGeometry(0.35, 0.35, 0.8, 28)
]
geos.forEach((g, i) => {
  const mesh = new THREE.Mesh(g, new THREE.MeshStandardMaterial({
    color: [0x60a5fa, 0xf472b6, 0x34d399, 0xfbbf24][i], roughness: 0.45
  }))
  // 平面几何体原点在中心；让物体坐在地面上需要抬高半个高度
  mesh.position.set(-3 + i * 1.3, 0.5, 0)
  mesh.userData.home = mesh.position.clone()
  scene.add(mesh)
  objects.push(mesh)
})

// DragControls：传入可拖数组、相机、事件元素
const dragControls = new DragControls(objects, camera, renderer.domElement)

// 拖拽期间关闭 OrbitControls，解决"边拖边转"
dragControls.addEventListener('dragstart', e => {
  controls.enabled = false
  e.object.material.emissive?.setHex(0x223344)
  renderer.domElement.style.cursor = 'grabbing'
})
dragControls.addEventListener('drag', e => {
  // 拖动时把物体压在地面高度，避免上下乱飞
  e.object.position.y = 0.5
  // 在回收区上方 → 区域变绿提示
  const inZone = Math.abs(e.object.position.x - zone.position.x) < 1.5 &&
                 Math.abs(e.object.position.z - zone.position.z) < 1.5
  zone.material.color.set(inZone ? 0x16a34a : 0xdc2626)
})
dragControls.addEventListener('dragend', e => {
  controls.enabled = true
  renderer.domElement.style.cursor = 'default'
  e.object.material.emissive?.setHex(0x000000)

  // 松手时若在回收区内，则"回收"（移回原位 + 提示）
  const inZone = Math.abs(e.object.position.x - zone.position.x) < 1.5 &&
                 Math.abs(e.object.position.z - zone.position.z) < 1.5
  if (inZone) {
    e.object.position.copy(e.object.userData.home)
  }
  zone.material.color.setHex(0xdc2626)
})
dragControls.addEventListener('hoveron',  () => renderer.domElement.style.cursor = 'grab')
dragControls.addEventListener('hoveroff', () => renderer.domElement.style.cursor = 'default')

renderer.setAnimationLoop(() => {
  objects.forEach(o => { if (!o.userData.dragging) o.rotation.y += 0.003 })
  controls.update()
  renderer.render(scene, camera)
})

常见问题解答 ​

Q1：为什么一拖物体相机也跟着转？

DragControls 和 OrbitControls 都响应同一个指针。在 dragstart 里 controls.enabled=false、dragend 里恢复即可，这是官方推荐的标准配合方式。

Q2：拖动物体会上下飘、甚至钻到地下？

默认拖拽平面面向相机，俯视角度下平面接近竖直，物体 y 会漂。在 drag 事件里强制 object.position.y = 固定值（桌面类场景），或自定义拖拽平面/改用 TransformControls。

Q3：只想让物体在水平 XZ 平面移动怎么办？

高级做法是监听 drag 事件后自己用 raycaster.ray.intersectPlane(horizontalPlane, point) 重算位置，其中 horizontalPlane 为 new THREE.Plane(new THREE.Vector3(0,1,0), 0)，再把 point 的 y 设为物体高度。

动手小练习 ​

  1. 把"回收归位"改成真正删除：scene.remove(obj) 并从 objects 数组剔除。
  2. 拖动时在物体下方显示一个贴地的圆形投影指示器。
  3. 尝试 TransformControls，切换 translate/rotate/scale 三种模式，对比自由拖拽与轴向操纵。
