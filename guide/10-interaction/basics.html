10.1 基础入门：Raycaster 射线拾取 ​

核心概念讲解 ​

浏览器只知道你点的是一块 <canvas>，并不知道点中了 3D 世界里的哪个物体。射线拾取（Raycasting） 解决"屏幕坐标 → 3D 物体"的映射：

  1. 鼠标点击的屏幕位置，配合相机，构造一条从相机出发、穿过该像素、射向场景深处的射线
  2. 用这条射线与场景里的物体求交，返回按距离排序的命中列表
  3. 命中的第一个物体就是用户点到的东西

术语解释：

  • NDC 坐标（标准化设备坐标）：把鼠标像素位置换算到 x,y ∈ [-1, 1]，原点在屏幕中心、y 向上（与 DOM 的 y 向下相反）。
  • 求交（Intersection）：判断射线与三角形/包围盒是否相交。返回对象含 point（交点）、distance、face（命中的三角面）、uv 等。

两个关键方法 ​

js
raycaster.setFromCamera(ndc, camera)         // 由鼠标 + 相机构造射线
const hits = raycaster.intersectObjects(list) // 求交，返回排序后的命中数组
hits[0].object                               // 最近命中的物体

hover 与 click 的区别 ​

  • hover：pointermove 里持续求交，命中就高亮/改光标
  • click：click 里求交。要防止拖拽旋转误触发点击：在 pointerdown 记录坐标，click 时若位移超过 5px 判定为拖拽而非点击

代码示例 ​

一组立方体，hover 高亮、click 选中并轻微弹起，HUD 显示当前选中：

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0b0e14)
const camera = new THREE.PerspectiveCamera(45, innerWidth / innerHeight, 0.1, 100)
camera.position.set(0, 3.5, 7)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
document.getElementById('app').appendChild(renderer.domElement)
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true
controls.target.set(0, 0.4, 0)

scene.add(new THREE.HemisphereLight(0xbfd9ff, 0x222222, 0.8))
const dir = new THREE.DirectionalLight(0xffffff, 1.8)
dir.position.set(3, 5, 4)
scene.add(dir)
scene.add(new THREE.GridHelper(12, 12, 0x334155, 0x1e293b))

const raycaster = new THREE.Raycaster()
const pointer = new THREE.Vector2()        // 复用，避免每帧 new
const pickables = []

// 4×3 立方体阵列
for (let i = 0; i < 12; i++) {
  const col = i % 4, row = Math.floor(i / 4)
  const mesh = new THREE.Mesh(
    new THREE.BoxGeometry(0.8, 0.8, 0.8),
    new THREE.MeshStandardMaterial({ color: 0x475569, roughness: 0.5 })
  )
  mesh.position.set((col - 1.5) * 1.4, 0.4, (row - 1) * 1.4)
  mesh.userData.baseColor = new THREE.Color(0x475569)
  mesh.userData.homeY = 0.4
  scene.add(mesh)
  pickables.push(mesh)
}

let hovered = null
let selected = null

// DOM 像素 → NDC（注意 y 取负：DOM 向下、NDC 向上）
function updatePointer(e) {
  const rect = renderer.domElement.getBoundingClientRect()
  pointer.x = ((e.clientX - rect.left) / rect.width) * 2 - 1
  pointer.y = -((e.clientY - rect.top) / rect.height) * 2 + 1
}

// 防拖拽误触：记录按下位置与时间
let downX = 0, downY = 0
renderer.domElement.addEventListener('pointerdown', e => {
  downX = e.clientX
  downY = e.clientY
})
renderer.domElement.addEventListener('pointermove', e => {
  updatePointer(e)
  raycaster.setFromCamera(pointer, camera)
  const hits = raycaster.intersectObjects(pickables)
  hovered = hits.length ? hits[0].object : null
  renderer.domElement.style.cursor = hovered ? 'pointer' : 'grab'
})
renderer.domElement.addEventListener('click', e => {
  // 位移过大 = 拖拽旋转，忽略本次点击
  if (Math.hypot(e.clientX - downX, e.clientY - downY) > 5) return
  updatePointer(e)
  raycaster.setFromCamera(pointer, camera)
  const hits = raycaster.intersectObjects(pickables)
  selected = hits.length ? hits[0].object : null
})

renderer.setAnimationLoop(() => {
  pickables.forEach(m => {
    // 优先级：选中 > 悬停 > 默认
    let targetColor = m.userData.baseColor
    let targetY = m.userData.homeY
    if (m === hovered) targetColor = new THREE.Color(0x38bdf8)
    if (m === selected) { targetColor = new THREE.Color(0xfbbf24); targetY = 0.75 }

    // 颜色与高度做平滑插值，避免突变
    m.material.color.lerp(targetColor, 0.18)
    m.position.y += (targetY - m.position.y) * 0.18
    m.rotation.y += 0.004
  })
  controls.update()
  renderer.render(scene, camera)
})

常见问题解答 ​

Q1：点击位置和实际物体对不上（偏移）？

多半是 NDC 换算没用 canvas 的 getBoundingClientRect()，或 canvas 不是全屏/有缩放。务必用相对 canvas 的偏移与实际宽高来算，示例写法在任意布局下都准。

Q2：点到的是子物体，但我想选中整个父 Group？

intersectObjects 默认返回具体命中的子 Mesh。可以沿 obj.parent 向上找到带标记的根（如查找 userData.selectable），或对父 Group 设置递归开关 intersectObjects(group.children, true) 后取 parent。

Q3：物体很多时每帧求交会不会卡？

Raycaster 内部先用包围球/包围盒粗筛，再测三角形，几十~几百个物体毫无压力。上万实例建议用 InstancedMesh（intersectObject 返回 instanceId）、八叉树（Octree）或 BVH 加速结构。

动手小练习 ​

  1. hover 时除了变色，显示一个跟随物体世界坐标的 3D 标签（Sprite）。
  2. 点击空白处取消选中（hits 为空时 selected=null）。
  3. 用命中返回的 hits[0].point 在点击位置生成一个小球标记，验证交点就是表面。
