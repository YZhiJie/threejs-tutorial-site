10.3 实战案例：3D 产品展厅（拾取 + 聚焦 + 信息面板） ​

核心概念讲解 ​

把前两篇的能力组合起来，就是一个常见的商业交互——3D 展厅 / 商品浏览器：

  • 多个展品在场景中陈列
  • hover：展品轻微放大、显示名称
  • click：相机平滑聚焦到展品、右侧弹出信息面板
  • 关闭面板：相机回到总览位置

相机聚焦：别用瞬移，用插值 ​

点击后直接 camera.position = ... 会很生硬。做法是记录起始位置/目标点，用缓动在约 0.8 秒内插值过去，期间禁用 OrbitControls，结束后再交还控制：

js
// 每帧逼近目标（阻尼跟随）
camera.position.lerp(focusPos, 0.1)
controls.target.lerp(focusTarget, 0.1)

术语解释：阻尼跟随（damped follow） 每帧朝目标靠近固定比例（如 0.1），自然形成"先快后慢"的 ease-out 运动，且无需显式计时。

交互状态机 ​

overview（总览）↔ focusing（镜头飞行中）↔ focused（已聚焦某展品）。用一个 state 变量管理，避免在飞行途中又触发拾取造成冲突。

代码示例 ​

三个展品 + 地面展台 + HTML 信息面板 + 相机聚焦飞行：

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import { RoomEnvironment } from 'three/addons/environments/RoomEnvironment.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0a0d14)
const camera = new THREE.PerspectiveCamera(45, innerWidth / innerHeight, 0.1, 100)
camera.position.set(0, 3.2, 7.5)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
renderer.toneMapping = THREE.ACESFilmicToneMapping
document.getElementById('app').appendChild(renderer.domElement)
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true
controls.target.set(0, 0.8, 0)

scene.environment = new THREE.PMREMGenerator(renderer)
  .fromScene(new RoomEnvironment(), 0.04).texture
scene.add(new THREE.HemisphereLight(0x8899bb, 0x111420, 0.4))

/* ---------- 展品数据 ---------- */
const products = [
  { id: 0, name: '极光环结', desc: '抛光金属环结雕塑，PBR 金属材质。',
    geo: () => new THREE.TorusKnotGeometry(0.55, 0.18, 160, 24),
    color: 0x60a5fa, metalness: 1, roughness: 0.15, pos: [-2.6, 1, 0] },
  { id: 1, name: '翡翠多面体', desc: '低多边形宝石，平面着色呈现棱面。',
    geo: () => new THREE.IcosahedronGeometry(0.7, 0),
    color: 0x34d399, metalness: 0.2, roughness: 0.25, flat: true, pos: [0, 1, 0] },
  { id: 2, name: '琥珀水晶', desc: '半透明物理材质，透射与折射效果。',
    geo: () => new THREE.OctahedronGeometry(0.72, 0),
    color: 0xfbbf24, metalness: 0, roughness: 0.05, transmission: 0.9, pos: [2.6, 1, 0] }
]

const pickables = []
products.forEach(p => {
  const mat = p.transmission !== undefined
    ? new THREE.MeshPhysicalMaterial({
        color: p.color, metalness: p.metalness, roughness: p.roughness,
        transmission: p.transmission, thickness: 0.8, ior: 1.6,
        flatShading: !!p.flat })
    : new THREE.MeshStandardMaterial({
        color: p.color, metalness: p.metalness, roughness: p.roughness,
        flatShading: !!p.flat })
  const mesh = new THREE.Mesh(p.geo(), mat)
  mesh.position.set(...p.pos)
  mesh.userData = { ...p, homeScale: 1 }
  scene.add(mesh)
  pickables.push(mesh)

  // 圆形展台
  const stand = new THREE.Mesh(
    new THREE.CylinderGeometry(0.85, 0.95, 0.5, 40),
    new THREE.MeshStandardMaterial({ color: 0x1b2230, roughness: 0.7 })
  )
  stand.position.set(p.pos[0], 0.25, p.pos[2])
  scene.add(stand)
})

/* ---------- 拾取 ---------- */
const raycaster = new THREE.Raycaster()
const pointer = new THREE.Vector2()
let hovered = null
let focused = null
let state = 'overview'   // overview | focusing | focused

let downX = 0, downY = 0
const cv = renderer.domElement
cv.addEventListener('pointerdown', e => { downX = e.clientX; downY = e.clientY })
cv.addEventListener('pointermove', e => {
  const r = cv.getBoundingClientRect()
  pointer.set(((e.clientX - r.left) / r.width) * 2 - 1,
             -((e.clientY - r.top) / r.height) * 2 + 1)
  raycaster.setFromCamera(pointer, camera)
  const hit = raycaster.intersectObjects(pickables)[0]
  hovered = state === 'overview' && hit ? hit.object : null
  cv.style.cursor = hovered ? 'pointer' : 'grab'
})
cv.addEventListener('click', e => {
  if (state !== 'overview') return
  if (Math.hypot(e.clientX - downX, e.clientY - downY) > 5) return
  if (!hovered) return
  focusOn(hovered)
})

// 面板"返回"按钮
document.getElementById('back').addEventListener('click', () => {
  focused = null
  state = 'focusing'
  showPanel(false)
})

function focusOn(obj) {
  focused = obj
  state = 'focusing'
  controls.enabled = false
  // 聚焦位置：在物体斜前方 2.6 单位
  const target = obj.position.clone()
  const dir = new THREE.Vector3().subVectors(camera.position, target).setY(0.6).normalize()
  camera.userData.focusPos = target.clone().add(dir.multiplyScalar(2.6)).setY(1.8)
  camera.userData.focusTarget = target
  showPanel(true, obj.userData)
}
function releaseFocus() {
  state = 'focusing'
  controls.enabled = false
  camera.userData.focusPos = new THREE.Vector3(0, 3.2, 7.5)
  camera.userData.focusTarget = new THREE.Vector3(0, 0.8, 0)
}

function showPanel(show, data) {
  const panel = document.getElementById('panel')
  panel.style.transform = show ? 'translateX(0)' : 'translateX(110%)'
  if (show && data) {
    document.getElementById('p-name').textContent = data.name
    document.getElementById('p-desc').textContent = data.desc
  }
}

renderer.setAnimationLoop(() => {
  pickables.forEach(m => {
    m.rotation.y += 0.005
    // hover 放大 1.1，focused 放大 1.18，其余 1
    const s = m === focused ? 1.18 : m === hovered ? 1.1 : 1
    m.scale.lerp(new THREE.Vector3(s, s, s), 0.15)
  })

  // 镜头飞行：阻尼逼近，足够近就切状态
  if (state === 'focusing' && camera.userData.focusPos) {
    camera.position.lerp(camera.userData.focusPos, 0.12)
    controls.target.lerp(camera.userData.focusTarget, 0.12)
    if (camera.position.distanceTo(camera.userData.focusPos) < 0.03) {
      state = focused ? 'focused' : 'overview'
      controls.enabled = true
    }
  }

  controls.update()
  renderer.render(scene, camera)
})

常见问题解答 ​

Q1：相机飞行途中还能点到别的展品，怎么处理？

用状态机。只有 state === 'overview' 时才允许 hover/click；focusing 飞行期间禁用拾取与 OrbitControls，到达后切到 focused。这样能杜绝飞行途中的冲突输入。

Q2：阻尼 lerp 会不会永远到不了终点？

理论上无限逼近。实践中设一个阈值（距离 < 0.03）就判定到达并切换状态、交还控制器，既自然又不会卡住。

Q3：展品信息面板为什么用 HTML 而不是 3D 文字？

HTML 面板更清晰、可选中复制、好做响应式与无障碍；3D 空间内的悬浮标注才用 Sprite/TextGeometry。产品详情这种 UI 信息交给 DOM 是更专业的选择。

动手小练习 ​

  1. 给每个展品加"换色"按钮，实时改 material.color。
  2. 聚焦时用 Raycaster 命中的 face.normal 决定相机停在哪一侧。
  3. 支持键盘左右方向键在展品间切换（自动从上一个聚焦飞向下一个）。
