3.3 实战案例：四视口多视角观察器 ​

核心概念讲解 ​

建模软件（Blender / Unity Editor）默认会在一个屏幕上同时显示透视 + 顶视 + 正视 + 侧视四个窗口。Three.js 用"一个 canvas、多次 render、scissor 裁剪"即可实现，不需要四个 WebGL 上下文（多上下文很耗资源且上限低）。

实现要点 ​

  1. 关闭自动清屏：renderer.autoClear = false，否则每次 render 会把前一个视口擦掉
  2. 开启 scissor 裁剪：renderer.setScissorTest(true)，渲染只影响指定矩形
  3. 每帧四次 render：每次先 setViewport + setScissor，再用不同相机 render
  4. 坐标换算：WebGL 视口原点在左下角，UI 标签原点在左上角，布局时 y 要翻转
  5. 只给透视视口挂 OrbitControls，三个正交视口保持固定观察角度

代码示例 ​

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x05070b)

const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
renderer.setSize(innerWidth, innerHeight)
renderer.autoClear = false        // 关键①：不自动清屏
renderer.setScissorTest(true)     // 关键②：开启裁剪
document.getElementById('app').appendChild(renderer.domElement)

// 透视相机（左上，可交互）
const persp = new THREE.PerspectiveCamera(50, 1, 0.1, 100)
persp.position.set(4, 4, 6)

// 三台正交相机，分别从三个轴向观察
function makeOrtho() {
  return new THREE.OrthographicCamera(-3, 3, 3, -3, 0.1, 100)
}
const top = makeOrtho()           // 顶视：在 +Y 上方往下看
top.position.set(0, 8, 0.0001)
top.lookAt(0, 0, 0)
const front = makeOrtho()         // 正视：在 +Z 往 -Z 看
front.position.set(0.0001, 2, 8)
front.lookAt(0, 0.5, 0)
const side = makeOrtho()          // 侧视：在 +X 往 -X 看
side.position.set(8, 2, 0.0001)
side.lookAt(0, 0.5, 0)

const controls = new OrbitControls(persp, renderer.domElement)
controls.enableDamping = true
controls.target.set(0, 0.5, 0)

/* ---------- 场景内容 ---------- */
scene.add(new THREE.HemisphereLight(0xbfd9ff, 0x202020, 0.8))
const dir = new THREE.DirectionalLight(0xffffff, 1.6)
dir.position.set(4, 7, 5)
scene.add(dir)
scene.add(new THREE.GridHelper(12, 12, 0x334155, 0x1e293b))
scene.add(new THREE.AxesHelper(2))

const group = new THREE.Group()
const m1 = new THREE.Mesh(new THREE.BoxGeometry(1.2, 1.2, 1.2),
  new THREE.MeshStandardMaterial({ color: 0x60a5fa }))
m1.position.set(-1.6, 0.6, 0)
const m2 = new THREE.Mesh(new THREE.CylinderGeometry(0.5, 0.5, 1.4, 32),
  new THREE.MeshStandardMaterial({ color: 0xf472b6 }))
m2.position.set(0.6, 0.7, -0.8)
const m3 = new THREE.Mesh(new THREE.SphereGeometry(0.7, 32, 24),
  new THREE.MeshStandardMaterial({ color: 0x34d399 }))
m3.position.set(1.4, 0.7, 1.2)
group.add(m1, m2, m3)
scene.add(group)

// 按视口宽高比更新正交范围，防止变形
function updateOrthoCameras(w, h) {
  const aspect = w / h
  for (const cam of [top, front, side]) {
    cam.left = -3 * aspect
    cam.right = 3 * aspect
    cam.top = 3
    cam.bottom = -3
    cam.updateProjectionMatrix()
  }
  persp.aspect = aspect
  persp.updateProjectionMatrix()
}
updateOrthoCameras(innerWidth / 2, innerHeight / 2)

// 在指定矩形（左下原点）内渲染一台相机
function renderViewport(camera, x, y, w, h) {
  renderer.setViewport(x, y, w, h)
  renderer.setScissor(x, y, w, h)
  renderer.render(scene, camera)
}

renderer.setAnimationLoop(() => {
  group.rotation.y += 0.004
  controls.update()

  const w = Math.floor(innerWidth / 2)
  const h = Math.floor(innerHeight / 2)

  renderer.clear(true, true, true)   // 整屏先清一次
  // WebGL 原点在左下角；与左上/右上/左下/右下的标签一一对应
  renderViewport(persp, 0, h, w, h)  // 左上：透视
  renderViewport(top,   w, h, w, h)  // 右上：顶视
  renderViewport(front, 0, 0, w, h)  // 左下：正视
  renderViewport(side,  w, 0, w, h)  // 右下：侧视
})

addEventListener('resize', () => {
  renderer.setSize(innerWidth, innerHeight)
  updateOrthoCameras(innerWidth / 2, innerHeight / 2)
})

常见问题解答 ​

Q1：为什么四个视口重叠/只显示最后一个？

忘了 renderer.autoClear = false。默认每次 render() 都会清屏，前一个视口刚画完就被下一次 render 清掉，只剩最后一个。

Q2：为什么视口之间有内容串到隔壁？

开启 scissorTest 后，必须在每次 render 前同时调用 setViewport 和 setScissor，且两者区域保持一致。只设 viewport 不设 scissor，渲染区域仍可能越过边界。

Q3：手机上分四屏太挤怎么办？

响应式策略：宽屏（桌面/横屏平板）用四宫格；窄屏用 Tab 在四个相机间切换，一次只显示一个。可用 matchMedia('(min-width: 768px)') 判断。

动手小练习 ​

  1. 给每个视口加边框线和左上角名称标签（透视/Top/Front/Side）。
  2. 让点击某个视口时把它"放大"成全屏，再点恢复四宫格。
  3. 把右上顶视图改成从下方仰视（bottom 视图），验证正交相机位置/朝向的设置方法。
