3.2 进阶应用：正交相机与相机控制器 ​

核心概念讲解 ​

OrthographicCamera：没有近大远小 ​

js
new THREE.OrthographicCamera(left, right, top, bottom, near, far)

透视相机用四棱锥投影，正交相机用一个长方体投影：平行线永远平行、物体无论远近大小一致。这让它非常适合：

  • 2.5D 游戏、等距视角（isometric）
  • 建模软件 / CAD 的三视图
  • 数据可视化图表

切换相机类型时，OrbitControls 需要绑定新相机。稳妥做法：记录旧相机的 position/rotation，复制给新相机后重建控制器，保持视角连续。

常用相机控制器（three/addons/controls/） ​

控制器交互方式典型用途
OrbitControls绕目标点旋转 / 平移 / 缩放产品展示、最常用
TrackballControls任意方向旋转，不锁极角自由观察（容易翻晕）
FlyControls像开飞机，带前后/转向飞行模拟
PointerLockControls锁定鼠标，第一人称转头FPS 游戏
DragControls直接拖拽场景物体编辑器、布局工具

多视口渲染（scissor test） ​

一个 canvas 上可以画多个相机画面，关键三行：

js
renderer.setScissorTest(true)   // 开启裁剪测试
renderer.setViewport(x, y, w, h) // 当前视口区域
renderer.setScissor(x, y, w, h)  // 当前裁剪区域（通常和 viewport 一致）

代码示例：透视 / 正交切换 ​

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import GUI from 'three/addons/libs/lil-gui.module.min.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0b0e14)

const perspCamera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100)
perspCamera.position.set(0, 2.2, 9)

// 正交相机先给 ±1 占位，正确范围在 updateOrtho() 里按宽高比设置
const FRUSTUM = 5
const orthoCamera = new THREE.OrthographicCamera(-1, 1, 1, -1, 0.1, 100)
orthoCamera.position.set(0, 2.2, 9)

const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
document.getElementById('app').appendChild(renderer.domElement)

// 让正交视口随画布宽高比伸缩，避免拉伸
function updateOrtho() {
  const aspect = innerWidth / innerHeight
  orthoCamera.left = -FRUSTUM * aspect / 2
  orthoCamera.right = FRUSTUM * aspect / 2
  orthoCamera.top = FRUSTUM / 2
  orthoCamera.bottom = -FRUSTUM / 2
  orthoCamera.updateProjectionMatrix()
}
updateOrtho()

scene.add(new THREE.AmbientLight(0xffffff, 0.55))
const dir = new THREE.DirectionalLight(0xffffff, 1.6)
dir.position.set(3, 6, 4)
scene.add(dir)
scene.add(new THREE.GridHelper(24, 24, 0x334155, 0x1e293b))

// 同样大小的球沿纵深排列：正交相机下它们看起来一样大
;[0x60a5fa, 0xf472b6, 0x34d399, 0xfbbf24].forEach((c, i) => {
  const s = new THREE.Mesh(
    new THREE.SphereGeometry(0.6, 32, 24),
    new THREE.MeshStandardMaterial({ color: c, roughness: 0.35 })
  )
  s.position.set(0, 0.6, -i * 3)
  scene.add(s)
})

let controls = new OrbitControls(perspCamera, renderer.domElement)
controls.enableDamping = true
let current = 'perspective'

const params = { camera: 'perspective' }
new GUI({ title: '相机' })
  .add(params, 'camera', ['perspective', 'orthographic'])
  .name('相机类型')
  .onChange(switchCamera)

function switchCamera(type) {
  const oldCam = current === 'perspective' ? perspCamera : orthoCamera
  const newCam = type === 'perspective' ? perspCamera : orthoCamera
  // 复制观察状态，切换后视角不跳变
  newCam.position.copy(oldCam.position)
  newCam.rotation.copy(oldCam.rotation)
  newCam.zoom = 1
  newCam.updateProjectionMatrix()

  controls.dispose()                                   // 解绑旧相机
  controls = new OrbitControls(newCam, renderer.domElement)
  controls.enableDamping = true
  current = type
}

renderer.setAnimationLoop(() => {
  controls.update()
  renderer.render(scene, current === 'perspective' ? perspCamera : orthoCamera)
})

addEventListener('resize', () => {
  renderer.setSize(innerWidth, innerHeight)
  perspCamera.aspect = innerWidth / innerHeight
  perspCamera.updateProjectionMatrix()
  updateOrtho()
})

常见问题解答 ​

Q1：正交相机画面为什么被拉扁了？

left/right/top/bottom 没有按画布宽高比设置。正交视口是矩形，高度固定时宽度要乘 aspect，否则圆会变椭圆。示例的 updateOrtho() 就是标准修正。

Q2：OrbitControls 在正交相机下滚轮为什么变化奇怪？

正交相机没有"距离"概念，滚轮缩放改的是 camera.zoom（而不是位置）。OrbitControls 已自动适配，但要记得缩放后它内部会调 updateProjectionMatrix，手动设置 zoom 时则要自己调。

Q3：怎么限制相机不要转到地面以下？

设置 controls.maxPolarAngle = Math.PI / 2 - 0.05（极角从 +Y 轴算起，90° 即地平线，留一点余量）。还可用 minDistance / maxDistance 限制缩放范围。

动手小练习 ​

  1. 在正交相机下把 OrbitControls 换成固定视角，用 camera.position + lookAt 做一个等距（isometric）俯视角。
  2. 给切换按钮加过渡动画：在 10 帧内把旧相机 position/rotation 插值到新相机。
