3.1 基础入门：透视相机与视锥体 ​

核心概念讲解 ​

相机决定"看到什么" ​

相机本身不渲染任何东西，它只是一个"观察者"：记录观察位置、朝向、投影方式。渲染时 Renderer 拿着相机的参数，把 3D 场景投影成 2D 画面。

PerspectiveCamera 的四个参数 ​

js
new THREE.PerspectiveCamera(fov, aspect, near, far)
  • fov（field of view，视场角）：垂直方向的视野张角，单位度。人眼约 60°；fov 越小越像望远镜（透视压缩），越大越像广角（边缘变形）
  • aspect：宽高比，通常等于画布 width / height，不匹配画面会拉伸
  • near / far：近裁面 / 远裁面距离。只有两者之间的物体才会渲染

术语解释：视锥体（Frustum） 是相机"看得见"的空间——一个被近、远两个平面削平的四棱锥。锥体外的物体会被裁掉（视锥剔除），不送进 GPU。

改相机参数后必须更新投影矩阵 ​

fov / aspect / near / far / zoom 任何一个改动后，必须调用：

js
camera.updateProjectionMatrix()

否则画面不会按新参数渲染。

代码示例 ​

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import GUI from 'three/addons/libs/lil-gui.module.min.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0b0e14)
const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100)
camera.position.set(0, 2.2, 9)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
document.getElementById('app').appendChild(renderer.domElement)
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true

scene.add(new THREE.AmbientLight(0xffffff, 0.55))
const dir = new THREE.DirectionalLight(0xffffff, 1.6)
dir.position.set(3, 6, 4)
scene.add(dir)
scene.add(new THREE.GridHelper(24, 24, 0x334155, 0x1e293b))

// 同样大小的立方体沿 z 轴纵深排列：近大远小的差异在它们身上最明显
const colors = [0x60a5fa, 0xf472b6, 0x34d399, 0xfbbf24, 0xa78bfa]
const cubes = colors.map((c, i) => {
  const mesh = new THREE.Mesh(
    new THREE.BoxGeometry(1, 1, 1),
    new THREE.MeshStandardMaterial({ color: c, roughness: 0.4 })
  )
  mesh.position.set(0, 0.5, -i * 3)
  scene.add(mesh)
  return mesh
})

const params = { fov: 50, near: 0.1, far: 100, zoom: 1 }
const gui = new GUI({ title: '相机参数' })
// 每个滑块改完立即 updateProjectionMatrix()
gui.add(params, 'fov', 15, 110, 1).name('fov 视场角').onChange(v => {
  camera.fov = v
  camera.updateProjectionMatrix()
})
gui.add(params, 'near', 0.1, 10, 0.1).name('near 近裁面').onChange(v => {
  camera.near = v
  camera.updateProjectionMatrix()
})
gui.add(params, 'far', 10, 60, 1).name('far 远裁面').onChange(v => {
  camera.far = v
  camera.updateProjectionMatrix()
})
gui.add(params, 'zoom', 0.4, 3, 0.05).name('zoom 缩放').onChange(v => {
  camera.zoom = v
  camera.updateProjectionMatrix()
})

renderer.setAnimationLoop(() => {
  cubes.forEach((m, i) => { m.rotation.y += 0.005 * (i + 1) })
  controls.update()
  renderer.render(scene, camera)
})

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight
  camera.updateProjectionMatrix()
  renderer.setSize(innerWidth, innerHeight)
})

常见问题解答 ​

Q1：fov 调大调小，相机没动，为什么画面变化这么大？

fov 改变的是"视锥体张角"。张角变小，同样屏幕能容纳的场景变少，物体显得更大（望远镜）；变大则容纳更多，边缘透视变形增强。它和"移动相机"都能改变取景，但机制完全不同。

Q2：near 设成 0.0001 为什么画面会闪烁 / 出现条纹？

这叫深度缓冲精度问题（z-fighting）。near 太小、far 太大时，深度值被压缩到极小范围，相邻表面深度无法区分而互相穿插。经验法则：near 尽量大（如 0.1）、far 按需要设（别一上来 10000）。

Q3：相机怎么"看向"某个物体？

用 camera.lookAt(target) 让相机朝向一个 Vector3。OrbitControls 内部每帧都会用 controls.target 覆盖朝向，所以用控制器时应该改 controls.target 而不是手动 lookAt。

动手小练习 ​

  1. 把 fov 固定在 50，沿 z 轴前后移动相机；再固定位置只改 fov，对比两种"取景"方式的差异。
  2. 故意把 near 设成 0.0001、far 设成 500，观察 z-fighting。
  3. 关闭 OrbitControls，用键盘方向键调 camera.position 并手动 lookAt(0,0,0)。
