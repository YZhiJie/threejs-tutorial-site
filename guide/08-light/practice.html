8.3 实战案例：三点布光法 ​

核心概念讲解 ​

三点布光（Three-Point Lighting）是摄影、电影、3D 渲染通用的经典布光法，用三盏灯各司其职：

三盏灯的参数直觉 ​

  • 主光 Key：强度最高（方向光约 2~3），通常带暖色调，放在相机一侧 30~45°
  • 补光 Fill：强度约为主光的 30~60%，冷色调，放在主光对侧；一般不投影（避免第二组杂乱阴影）
  • 轮廓光 Rim/Back：放在主体后上方朝主体打，强调肩/头顶一圈亮边；强度可较高

为什么补光不投影：多盏灯各自投影会产生方向矛盾的多重阴影，画面脏乱。通常只让主光投影，补光与轮廓光关闭 castShadow。

再补一盏环境光 ​

三灯之外通常加一个极弱的 HemisphereLight（0.15~0.3），保证最深的阴影里仍有一点颜色细节，而不是纯黑。

代码示例 ​

对一个"角色感"物体（胶囊 + 球头）做三点布光，每盏灯可独立开关/调色/调强，并显示光源位置：

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import GUI from 'three/addons/libs/lil-gui.module.min.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0b0e14)
const camera = new THREE.PerspectiveCamera(42, innerWidth / innerHeight, 0.1, 100)
camera.position.set(0, 2.2, 6)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
renderer.shadowMap.enabled = true
renderer.shadowMap.type = THREE.PCFShadowMap // r186 默认（PCFSoft 已移除）
document.getElementById('app').appendChild(renderer.domElement)
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true
controls.target.set(0, 1, 0)

// 极弱环境光：保留暗部颜色
scene.add(new THREE.HemisphereLight(0x8899bb, 0x111420, 0.2))

const ground = new THREE.Mesh(
  new THREE.PlaneGeometry(20, 20),
  new THREE.MeshStandardMaterial({ color: 0x1c2330, roughness: 0.95 })
)
ground.rotation.x = -Math.PI / 2
ground.receiveShadow = true
scene.add(ground)

// 主体：胶囊身体 + 球头，模拟"人物/产品"
const bodyMat = new THREE.MeshStandardMaterial({ color: 0x8ea3c4, roughness: 0.55 })
const body = new THREE.Mesh(new THREE.CapsuleGeometry(0.55, 0.9, 8, 32), bodyMat)
body.position.y = 1.1
body.castShadow = true
const head = new THREE.Mesh(new THREE.SphereGeometry(0.34, 32, 24),
  new THREE.MeshStandardMaterial({ color: 0xe8d7c2, roughness: 0.6 }))
head.position.y = 2.05
head.castShadow = true
scene.add(body, head)

/* ---------- 三盏灯 ---------- */
// 主光：前右上方，暖色，唯一投影
const key = new THREE.DirectionalLight(0xfff1d6, 2.6)
key.position.set(4, 5, 4)
key.castShadow = true
key.shadow.mapSize.set(2048, 2048)
key.shadow.camera.left = -5; key.shadow.camera.right = 5
key.shadow.camera.top = 5; key.shadow.camera.bottom = -5

// 补光：前左方，冷色，较弱，不投影
const fill = new THREE.DirectionalLight(0xbfd6ff, 0.9)
fill.position.set(-4, 2.5, 3)

// 轮廓光：后上方，偏冷白，打亮头顶/肩边缘
const rim = new THREE.DirectionalLight(0xddeeff, 2.2)
rim.position.set(0, 4.5, -5)

scene.add(key, fill, rim)

// 光源位置小球
function marker(light, color) {
  const m = new THREE.Mesh(new THREE.SphereGeometry(0.12, 12, 8),
    new THREE.MeshBasicMaterial({ color }))
  m.position.copy(light.position)
  scene.add(m)
  return m
}
const mk = marker(key, 0xfff1d6)
const mf = marker(fill, 0xbfd6ff)
const mr = marker(rim, 0xddeeff)

const params = {
  keyOn: true, keyI: 2.6,
  fillOn: true, fillI: 0.9,
  rimOn: true, rimI: 2.2,
  markers: true
}
const gui = new GUI({ title: '三点布光' })
const kf = gui.addFolder('主光 Key')
kf.add(params, 'keyOn').name('开关').onChange(v => key.visible = v)
kf.add(params, 'keyI', 0, 5, 0.05).name('强度').onChange(v => key.intensity = v)
const ff = gui.addFolder('补光 Fill')
ff.add(params, 'fillOn').name('开关').onChange(v => fill.visible = v)
ff.add(params, 'fillI', 0, 3, 0.05).name('强度').onChange(v => fill.intensity = v)
const rf = gui.addFolder('轮廓光 Rim')
rf.add(params, 'rimOn').name('开关').onChange(v => rim.visible = v)
rf.add(params, 'rimI', 0, 5, 0.05).name('强度').onChange(v => rim.intensity = v)
gui.add(params, 'markers').name('显示光源位置').onChange(v =>
  [mk, mf, mr].forEach(m => m.visible = v))

renderer.setAnimationLoop(() => {
  controls.update()
  renderer.render(scene, camera)
})

常见问题解答 ​

Q1：为什么不用三盏强度一样的灯？

等强光会从各个方向均匀照亮，明暗对比被抹平，主体缺乏体积感和主次。三点布光靠"主光强、补光弱、轮廓光点睛"的强度差塑造形态——光影对比本身就是立体感的来源。

Q2：补光为什么常带冷色，主光带暖色？

这是模拟自然光的习惯：阳光（主光）偏暖，天空散射（补光）偏冷。暖冷对比让画面更有层次；当然风格化场景也可反过来用，关键是两光有色温差。

Q3：产品渲染还需要加什么灯？

三点布光之外，产品/金属常加一个大的柔光环境（RoomEnvironment 或大的 RectAreaLight 提供大面积高光反射），因为光滑表面的质感主要来自"对大光源形状的反射"。

动手小练习 ​

  1. 只开主光和补光，调整补光强度从 0 到等于主光，观察立体感如何被逐渐抹平。
  2. 把轮廓光颜色改成青色、强度拉高，做出"科技感边缘光"。
  3. 给主体换高金属度材质，加一盏 RectAreaLight 作为大面积柔光，观察表面反射形状。
