8.2 进阶应用：阴影原理与调优 ​

核心概念讲解 ​

阴影是怎么生成的（Shadow Map） ​

Three.js 默认使用**阴影贴图（Shadow Map）**技术，分两遍渲染：

  1. 从光源视角渲染一遍场景，记录每个像素离光源最近的深度 → 一张深度图（shadow map）
  2. 从相机视角正常渲染时，把每个片段投影到光源空间，比较它与深度图：更远就说明被挡住 → 处于阴影中

术语解释：

  • 阴影相机（shadow camera）：以光源为视点的一台正交相机（平行光）或透视相机（聚光灯），它的范围决定"哪些区域参与阴影计算"。
  • 阴影偏移（bias）：深度比较时的一个微调量，用来消除"阴影痤疮（shadow acne）"。

阴影清晰的三个杠杆 ​

  1. shadow.mapSize：阴影贴图分辨率（1024/2048/4096），越大越清晰、越贵
  2. shadow camera 范围：left/right/top/bottom 框得越紧，同样分辨率覆盖范围越小 → 越清晰
  3. shadow.bias / normalBias：消除痤疮与"悬浮感（peter-panning）"之间的平衡

常见阴影瑕疵 ​

  • 阴影痤疮（acne）：表面上出现条纹状自阴影 → 适当增大 bias（负值，如 -0.0005）或 normalBias（如 0.02）
  • 物体悬空（peter-panning）：阴影和物体底部之间有缝隙 → bias 调过头了，往回收
  • 阴影锯齿/边缘硬：提高 mapSize、收紧相机范围；想要柔和模糊边缘可换用 VSMShadowMap 并调 light.shadow.radius

r186 阴影类型变更（重要） ​

旧教程里常见的 THREE.PCFSoftShadowMap 在 r186 已被移除——运行时使用会在控制台告警并自动回退到 PCFShadowMap。现在可选的三种：

  • THREE.BasicShadowMap：不过滤，边缘最硬（性能最好）
  • THREE.PCFShadowMap：百分比渐近过滤，默认值，绝大多数场景直接用它
  • THREE.VSMShadowMap：方差阴影，配合 light.shadow.radius（模糊半径）与 light.shadow.blurSamples 得到柔和边缘；代价是多一遍模糊 pass，且可能出现"漏光（light bleeding）"

想让普通 PCF 阴影边缘更柔和，优先提高 mapSize + 收紧阴影相机范围；只有确实需要高斯般的模糊边缘时才上 VSM。

代码示例 ​

一个"立柱投阴影"实验台，把 mapSize、相机范围、bias 全部做成可实时调节：

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import GUI from 'three/addons/libs/lil-gui.module.min.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0b0e14)
const camera = new THREE.PerspectiveCamera(45, innerWidth / innerHeight, 0.1, 100)
camera.position.set(0, 4, 8)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
renderer.shadowMap.enabled = true
renderer.shadowMap.type = THREE.PCFShadowMap // r186 默认；PCFSoft 已移除，柔边改用 VSM
document.getElementById('app').appendChild(renderer.domElement)
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true
controls.target.set(0, 0.8, 0)

scene.add(new THREE.HemisphereLight(0xbfd9ff, 0x222222, 0.5))

const sun = new THREE.DirectionalLight(0xffffff, 2)
sun.position.set(4, 7, 3)
sun.castShadow = true
sun.shadow.mapSize.set(1024, 1024)
// 阴影相机范围：越小越清晰
sun.shadow.camera.near = 1
sun.shadow.camera.far = 25
sun.shadow.camera.left = -6
sun.shadow.camera.right = 6
sun.shadow.camera.top = 6
sun.shadow.camera.bottom = -6
sun.shadow.bias = -0.0002
sun.shadow.normalBias = 0.02
scene.add(sun)

// 可视化阴影相机的范围（辅助理解"框得越紧越清晰"）
const camHelper = new THREE.CameraHelper(sun.shadow.camera)
camHelper.visible = false
scene.add(camHelper)

const ground = new THREE.Mesh(
  new THREE.PlaneGeometry(24, 24),
  new THREE.MeshStandardMaterial({ color: 0x2a3242, roughness: 0.95 })
)
ground.rotation.x = -Math.PI / 2
ground.receiveShadow = true
scene.add(ground)

// 几根不同高度的立柱，投出有层次的阴影
;[0.6, 1.2, 2, 1.6].forEach((h, i) => {
  const p = new THREE.Mesh(
    new THREE.BoxGeometry(0.5, h, 0.5),
    new THREE.MeshStandardMaterial({ color: 0x60a5fa, roughness: 0.5 })
  )
  p.position.set(-2.4 + i * 1.6, h / 2, 0)
  p.castShadow = p.receiveShadow = true
  scene.add(p)
})

const params = {
  mapSize: 1024,
  shadowRange: 6,
  bias: -0.0002,
  normalBias: 0.02,
  showHelper: false
}
function applyMapSize() {
  // 切换阴影贴图分辨率前，必须释放旧的渲染目标
  sun.shadow.map?.dispose()
  sun.shadow.map = null
  sun.shadow.mapSize.set(params.mapSize, params.mapSize)
}
const gui = new GUI({ title: '阴影调优' })
gui.add(params, 'mapSize', [256, 512, 1024, 2048, 4096]).name('mapSize').onChange(() => {
  applyMapSize()
})
gui.add(params, 'shadowRange', 2, 16, 0.5).name('相机范围').onChange(v => {
  sun.shadow.camera.left = -v
  sun.shadow.camera.right = v
  sun.shadow.camera.top = v
  sun.shadow.camera.bottom = -v
  sun.shadow.camera.updateProjectionMatrix()
})
gui.add(params, 'bias', -0.005, 0.005, 0.0001).name('bias').onChange(v => sun.shadow.bias = v)
gui.add(params, 'normalBias', 0, 0.1, 0.005).name('normalBias')
  .onChange(v => sun.shadow.normalBias = v)
gui.add(params, 'showHelper').name('显示阴影相机').onChange(v => camHelper.visible = v)

renderer.setAnimationLoop(() => {
  controls.update()
  renderer.render(scene, camera)
})

常见问题解答 ​

Q1：开了 castShadow 还是没有阴影？

检查三件套：renderer.shadowMap.enabled、light.castShadow、mesh.castShadow + ground.receiveShadow。另外只有 Directional / Spot / Point 三种灯能投影，Ambient/Hemisphere 不能。

Q2：阴影边缘有波浪/条纹（acne）怎么办？

先小幅增大负 bias（如 -0.0002 → -0.0005），或用 normalBias（沿法线偏移，0.02 起步）。平面上 acne 优先调 bias，曲面上 normalBias 更有效。

Q3：改了 shadow.mapSize 没效果？

阴影贴图在首次渲染时按当时的 mapSize 创建，之后改数字不会自动重建。必须先 sun.shadow.map?.dispose(); sun.shadow.map = null，下一帧才会用新分辨率重建（示例已封装）。

动手小练习 ​

  1. 在 mapSize=1024 下，把阴影相机范围从 16 逐步收到 2，量化观察清晰度提升。
  2. 把 renderer.shadowMap.type 在 Basic / PCF / VSM 间切换；用 VSM 时给 sun.shadow.radius 设 2~6 观察柔边效果（r186 已无 PCFSoft）。
  3. 换用 SpotLight 投影，观察它的阴影相机是透视锥体（越远越糊）。
