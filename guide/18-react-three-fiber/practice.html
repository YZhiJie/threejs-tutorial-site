18.3 实战案例：可复用 3D 组件库 ​

前置提示：本篇属于精通方向扩展内容，建议先完成基础模块 ⑪ 再学习本篇。

核心概念讲解 ​

前两篇的知识只有沉淀成可复用组件才真正产生复利。本篇封装两个最常见的积木：<SceneCanvas />（统一基础设施：阴影/相机/环境）与 <ProductViewer />（Props 驱动的业务单元：模型/颜色/自动旋转/标注）。做完你会得到一个可以直接搬进真实项目的最小 3D 组件库。

目标：两个积木各管一层 ​

  • <SceneCanvas />：所有页面统一的 Canvas 配置——阴影开关、像素比、默认相机、环境贴图、接触阴影、轨道控制器。业务页面不再重复这些样板。
  • <ProductViewer />：一个"产品展示位"，父级只给 props（modelUrl、color、autoRotate、annotations），内部自己处理加载、旋转与标注。

组件设计原则 ​

何时拆组件——三条经验信号，满足任意一条就拆：

  1. 同一段 JSX 出现第二次（复制粘贴是拆分的第一信号）；
  2. 一个组件同时管好几件事（加载模型 + 布光 + UI 标注）——按职责拆；
  3. 某个节点有独立的每帧动画/状态——拆出去让它拥有自己的 useFrame，卸载时动画自动注销。

Props vs zustand——上一篇表格的组件库版本：

状态性质放哪例子
组件配置，由父级决定、变化频率低PropsmodelUrl、color、autoRotate
跨多个组件共享，或 Canvas 内外都要读写zustand全局主题色、当前选中产品
每帧都在变的量ref + useFrame，不进任何状态库旋转累计角、动画进度

一句话：组件库对外暴露 props，跨页全局态进 store，每帧动画留 ref。

代码示例 ​

三个文件，完整可运行。先是统一基础设施：

jsx
// src/components/SceneCanvas.jsx —— 统一 Canvas 配置：阴影/相机/环境
import { Canvas } from '@react-three/fiber'
import { OrbitControls, Environment, ContactShadows } from '@react-three/drei'

export function SceneCanvas({
  children,
  cameraPosition = [4, 3, 6],
  environment = 'city',
  shadows = true,
  contactShadows = true,
  autoRotate = false,
}) {
  return (
    <Canvas
      shadows={shadows}
      dpr={[1, 2]}
      camera={{ position: cameraPosition, fov: 45 }}
      style={{ height: '100vh' }}
    >
      <color attach="background" args={['#0b0e14']} />
      <ambientLight intensity={0.25} />
      <directionalLight
        position={[5, 8, 5]}
        intensity={2}
        castShadow={shadows}
        shadow-mapSize={[2048, 2048]}
      />
      {environment && <Environment preset={environment} />}
      {children}
      {contactShadows && (
        <ContactShadows position={[0, -1.7, 0]} opacity={0.55} blur={2.2} scale={10} />
      )}
      <OrbitControls enableDamping makeDefault autoRotate={autoRotate} autoRotateSpeed={1.2} />
    </Canvas>
  )
}

再是 Props 驱动的产品展示位。注意 glTF 模型单独拆成 <GltfModel />——useGLTF 是 hook，不能写在条件分支里，按组件拆同时让加载态可以被 Suspense 接管：

jsx
// src/components/ProductViewer.jsx —— Props 驱动：modelUrl/颜色/自动旋转/标注
import { useMemo, useRef } from 'react'
import { useFrame } from '@react-three/fiber'
import { Html, useGLTF } from '@react-three/drei'

function GltfModel({ url, color }) {
  const { scene } = useGLTF(url)
  // 克隆一份再改色，避免污染 useGLTF 的全局缓存（别处可能复用同一模型）
  const cloned = useMemo(() => {
    const c = scene.clone(true)
    c.traverse((o) => {
      if (o.isMesh) {
        o.castShadow = true
        if (color) {
          o.material = o.material.clone()
          o.material.color.set(color)
        }
      }
    })
    return c
  }, [scene, color])
  return <primitive object={cloned} />
}

function FallbackProduct({ color }) {
  // 没有 modelUrl 时的内置占位模型
  return (
    <mesh castShadow>
      <torusKnotGeometry args={[0.9, 0.3, 180, 24]} />
      <meshStandardMaterial color={color} roughness={0.3} metalness={0.2} />
    </mesh>
  )
}

export function ProductViewer({
  modelUrl,
  color = '#4f9cf9',
  autoRotate = false,
  annotations = [],
}) {
  const group = useRef()
  useFrame((_, delta) => {
    if (autoRotate && group.current) group.current.rotation.y += delta * 0.6
  })
  return (
    <group ref={group}>
      {modelUrl ? <GltfModel url={modelUrl} color={color} /> : <FallbackProduct color={color} />}
      {annotations.map((a) => (
        <Html key={a.text} position={a.position} center distanceFactor={8}>
          <div style={{ background: '#0b1220cc', color: '#7dd3fc', padding: '4px 10px', borderRadius: 8, whiteSpace: 'nowrap' }}>
            {a.text}
          </div>
        </Html>
      ))}
    </group>
  )
}

业务页面只剩"描述要什么"：

jsx
// src/App.jsx
import { SceneCanvas } from './components/SceneCanvas'
import { ProductViewer } from './components/ProductViewer'

export default function App() {
  return (
    <SceneCanvas>
      <ProductViewer
        color="#f472b6"
        autoRotate
        annotations={[
          { text: 'PBR 外壳', position: [1.4, 0.8, 0] },
          { text: '磁吸底座', position: [0, -1.3, 0] },
        ]}
      />
    </SceneCanvas>
  )
}

需求变更时——换颜色、关旋转、加一条标注——都只动 App.jsx 里的一行 props，两个组件一行不改。

常见问题解答 ​

Q1：为什么 GltfModel 必须拆成独立组件？

两个原因：其一，useGLTF 是 hook，React 禁止在条件分支里调用 hook（{modelUrl ? useGLTF(...) : ...} 会直接报错）；其二，useGLTF 加载期间会挂起组件，拆出去后配合 <Suspense> 可以只让模型区域显示加载态，而不是整页白屏。这是 R3F 组件库的标准拆法。

Q2：一个页面放好几个 ProductViewer 会卡吗？

每个 <SceneCanvas> 都是一个独立的 WebGL 上下文，浏览器对同时存活的上下文数有硬上限（约 8~16 个），超出后最先创建的被强制销毁。同屏多展示位请共用一个 Canvas，或用 drei 的 <View> 组件在单个 canvas 上切出多个视口。

Q3：模型不是 glb 格式（obj/fbx）怎么办？

drei 提供 useFBX、useOBJ 等对应加载 hook，把 GltfModel 换个壳即可。但更推荐按 15 模块的资产管线统一转成 glTF：体积小、带 PBR 材质、可被 useGLTF 缓存，组件库只需维护一条加载路径。

Q4：SceneCanvas 里要不要把 Environment、ContactShadows 写死？

写默认值、留 props 开关（如本篇的 environment、contactShadows）是组件库的常见做法：多数页面零配置获得一致观感，特殊页面传 environment={null} 关掉即可。写死不可配才是问题。

动手小练习 ​

  1. 给 <SceneCanvas /> 加 background prop（默认 '#0b0e14'），让营销页可以一键换浅色背景。
  2. 给 <ProductViewer /> 加 wireframe prop，透传到占位模型与 glTF 模型的材质上。
  3. 把 annotations 从 props 改成 zustand 驱动：点击模型时向 store 追加一条标注（位置取点击事件 e.point），体会"props 配置 + store 动态数据"的边界。
