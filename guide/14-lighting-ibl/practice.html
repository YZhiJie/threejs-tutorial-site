14.3 实战案例：高保真产品渲染 ​

前置提示：本篇属于精通方向扩展内容，建议先完成基础模块 ⑥⑧ 再学习本篇。

核心概念讲解 ​

打开任何一个汽车官网的 3D 展车页，配方其实都一样：clearcoat 车漆 + HDR 环境 + 软阴影地台 + 色调映射。前两篇把每个零件都讲透了，本篇把它们拧成一台能转的展车台——对标汽车官网的最小可用形态。

配方拆解 ​

  1. 车漆 = 双层材质：真实车漆是"色漆层 + 清漆层"的结构。MeshPhysicalMaterial 的 clearcoat 精确对应——底色层负责颜色与金属颗粒感（metalness 拉高），清漆层是一层透明镜面，负责那道锐利的环境倒影；
  2. HDR 供光、压暗做背景：scene.environment 给反射内容，同一张图作 scene.background 时用 backgroundIntensity 压暗，展车才是主角；
  3. 软阴影地台：圆形地台 + 收紧阴影相机的方向光，车底那圈接触阴影是"落地感"的来源；
  4. ACES + 曝光定调：电影感洗印，曝光旋钮做最后微调；
  5. 展台自转 + 环境旋转：转展台看高光流动；environmentRotation 转环境图，等于绕着车"找光"。

为什么是 clearcoat 而不是把 roughness 调低 ​

把普通材质的 roughness 调到 0.1 也能得到光滑表面，但那是"单层光滑"——倒影和高光糊在一起。clearcoat 是独立的第二层镜面：底色层保持 0.3 的柔和散射，清漆层单独给出锐利倒影，两层高光叠加出来的"深邃感"才是车漆的味。

代码示例 ​

展车台核心代码（演示文件即此实现，逐段注释）：

js
import * as THREE from 'three'
import { RGBELoader } from 'three/addons/loaders/RGBELoader.js'

// ---- ① 渲染器：ACES 洗印 + 开阴影 ----
renderer.toneMapping = THREE.ACESFilmicToneMapping
renderer.toneMappingExposure = 1.1
renderer.shadowMap.enabled = true
renderer.shadowMap.type = THREE.PCFShadowMap

// ---- ② HDR 环境：供反射与照明，背景压暗突出展车 ----
const pmrem = new THREE.PMREMGenerator(renderer)
new RGBELoader().load(HDR_URL, (tex) => {
  tex.mapping = THREE.EquirectangularReflectionMapping
  scene.environment = pmrem.fromEquirectangular(tex).texture // 光照用预过滤版
  scene.environmentIntensity = 1.1
  scene.background = tex                                     // 背景用原始清晰图
  scene.backgroundIntensity = 0.4   // 同一张图，但当配角
})

// ---- ③ 软阴影钥匙光：收紧相机 = 免费的清晰度 ----
const keyLight = new THREE.DirectionalLight(0xffffff, 2.2)
keyLight.position.set(4, 6, 3)
keyLight.castShadow = true
keyLight.shadow.mapSize.set(2048, 2048)
keyLight.shadow.camera.left = keyLight.shadow.camera.bottom = -4.5
keyLight.shadow.camera.right = keyLight.shadow.camera.top = 4.5
keyLight.shadow.bias = -0.0002
keyLight.shadow.normalBias = 0.03
scene.add(keyLight)

// ---- ④ 车漆材质：金属底色层 + clearcoat 清漆层 ----
const paint = new THREE.MeshPhysicalMaterial({
  color: 0xb3162e,                 // 车漆底色
  metalness: 0.85,                 // 金属颗粒感
  roughness: 0.3,                  // 色漆层的柔和散射
  clearcoat: 1.0,                  // 清漆层强度：锐利环境倒影
  clearcoatRoughness: 0.06,        // 清漆层自身的粗糙度
  envMapIntensity: 1.25            // 反射略增强，展厅感
})

// 车侧轮廓 → 沿宽度拉伸成车身（纯几何体概念车，零外部资产）
const profile = new THREE.Shape()
profile.moveTo(-2.3, 0.4)
// …尾部、甲板、引擎盖、车头的曲线（见演示文件）…
const bodyGeo = new THREE.ExtrudeGeometry(profile, {
  depth: 1.5, bevelEnabled: true,
  bevelThickness: 0.08, bevelSize: 0.08, bevelSegments: 6
})
const body = new THREE.Mesh(bodyGeo, paint)
body.castShadow = true
scene.add(body)

// ---- ⑤ 圆形地台：接住接触阴影 ----
const platform = new THREE.Mesh(
  new THREE.CylinderGeometry(3.6, 3.6, 0.12, 64),
  new THREE.MeshStandardMaterial({ color: 0x151b28, roughness: 0.32, metalness: 0.7 })
)
platform.receiveShadow = true
scene.add(platform)

// ---- ⑥ 环境旋转：光照与背景一起转，等于绕车找光 ----
function setEnvRotation(deg) {
  const rad = deg * Math.PI / 180
  scene.environmentRotation.y = rad
  scene.backgroundRotation.y = rad
}

lil-gui 面板接四个旋钮：车漆颜色（paint.color）、clearcoat（0→1 看哑光漆效果）、曝光（toneMappingExposure）、环境旋转（上面的 setEnvRotation），外加展台自动旋转与速度——完整接线见演示文件。

常见问题解答 ​

Q1：clearcoat 调了没效果，车漆还是哑的？

清漆层反射的是环境与灯光的高光——先确认 scene.environment 已就位（没有反射内容，clearcoat 巧妇难为无米之炊）；再确认材质是 MeshPhysicalMaterial（Standard 没有 clearcoat 属性）。都对了还没倒影，把 envMapIntensity 提到 1.2 左右看看。

Q2：HDR 背景太抢戏，观众都去看风景了？

产品页的经典处理：背景压暗或干脆不要。① scene.backgroundIntensity = 0.3~0.6，同一张图当配角；② scene.background 换纯色（如深灰蓝），只留 scene.environment 供光照——车身照样映着日落，画面却干干净净；③ 想要摄影棚感还可以用 scene.backgroundBlurriness 把背景打糊。

Q3：搬到移动端就掉帧，怎么瘦身？

按性价比排序：① HDR 换 1k 档（作光照看不出区别）；② 阴影 mapSize 2048→1024；③ setPixelRatio(Math.min(devicePixelRatio, 1.5)) 压低渲染分辨率；④ 展台、轮毂等装饰几何减面。clearcoat 本身开销不大，可以保留——质感是产品页的命。

Q4：车漆调不出金属感，像塑料？

金属感三要素齐才成立：metalness 拉到 0.8~1.0（金属颗粒）、roughness 保持 0.25~0.35（色漆层别太光）、envMapIntensity 1.2 左右（倒影够亮）。深色车漆（纯黑、深蓝）尤其依赖 clearcoat——没有清漆层的锐利倒影，黑车就是一团黑。

动手小练习 ​

  1. 把"环境旋转"从 0° 慢慢拖到 360°，找到轮毂高光最亮的角度——这就是产品摄影师扛灯绕车走位时在干的事。
  2. clearcoat 从 1 拉到 0，车漆变"哑光漆"，再拉回去——单独感受清漆层贡献的那道锐利倒影。
  3. 车漆改纯白、曝光降到 0.8，模拟"珍珠白官图"；再换纯黑、曝光 1.3，体会深色车对曝光与环境强度的敏感度。
