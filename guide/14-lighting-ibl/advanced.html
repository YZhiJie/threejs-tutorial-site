14.2 进阶应用：光照探针与阴影调优 ​

前置提示：本篇属于精通方向扩展内容，建议先完成基础模块 ⑥⑧ 再学习本篇。

核心概念讲解 ​

LightProbe：把环境光压缩成 27 个数 ​

scene.environment 提供的是带方向细节的反射——高光里能看到窗户和太阳。但有些场景不需要这么"高清"的环境：

  • 同一场景里有多个局部光照区域（室内/洞穴/驾驶舱），每个区域想要自己的环境光；
  • 低配设备上要一个几乎零开销的近似方案。

LightProbe（光照探针） 把某个点的 360° 环境光压缩成 9 个球谐系数（SH3，共 27 个浮点数）：亮暗与色温都对，但没有清晰倒影——是"环境光的低分辨率快照"。LightProbeGenerator 能从一次立方体渲染现场生成：

js
import { LightProbeGenerator } from 'three/addons/lights/LightProbeGenerator.js'

// 用 CubeCamera 在目标位置拍一张 360° 快照
const cubeRT = new THREE.WebGLCubeRenderTarget(256)
const cubeCam = new THREE.CubeCamera(0.1, 100, cubeRT)
cubeCam.update(renderer, scene)   // 拍！

// 快照 → 球谐系数 → 光照探针，挂进场景即生效
const probe = LightProbeGenerator.fromCubeRenderTarget(renderer, cubeRT)
scene.add(probe)

与 scene.environment 不冲突，两者可叠加：environment 管"看得见的倒影"，探针管"感受不到但缺了就不对的环境底光"。

阴影调优：四个旋钮与一张免费地图 ​

8.2 讲过 mapSize / bias / normalBias 的基础用法，本篇把它们做成可实时拖动的调优台，并补上每个旋钮的"为什么"：

参数治什么病调过头的副作用
shadow.mapSize边缘锯齿、阴影发糊显存与绘制开销，2048 是甜点
shadow.bias（负值）阴影痤疮（表面条纹状自阴影）阴影悬空（peter-panning）
shadow.normalBias斜面/曲面上的条纹阴影与物体底部分离
shadow.radius边缘柔化：PCF 下扩散采样、VSM 下模糊半径过大阴影发虚失真

还有第五个零成本旋钮常被忽略：收紧阴影相机范围。方向光的阴影贴图分辨率是"摊"在正交相机盒子上的，盒子从 ±14 收到 ±4，等效分辨率提升三倍多，不花一分钱显存。演示里打开"相机辅助线"能直观看到这个盒子罩住了谁。

CSM：大场景的级联阴影 ​

单张阴影贴图罩不住整个开放世界：近了锯齿、远了没影。CSM（Cascaded Shadow Maps，级联阴影贴图） 把相机视锥按距离切成 3~4 段，每段配一张独立阴影贴图——近处小段高密度，远处大段将就着用。Three.js 在 three/addons/csm/CSM.js 提供了现成实现。

适用判断一句话：户外大场景、载具视角才需要 CSM；产品页、房间级场景，单张 2048 + 收紧相机盒子已经绰绰有余，别为用不上的东西付多级渲染的帧税。

色调映射与曝光：最后一步的"洗印" ​

HDR 光照算出的是物理亮度（可以远超 1），tone mapping 负责把它压回屏幕的 0~1。r186 可选的模式里重点记三个：

模式性格适用
ACESFilmic电影感：高光柔和滚落、对比强、略偏暖产品展示/汽车官网的万金油
AgX极亮处不漂色，高光保留最好强光源、霓虹、发光体多的场景
Neutral饱和度最忠实，最接近"原图"电商白底图等颜色敏感的商品

toneMappingExposure 是洗印间的总旋钮：场景换 HDR 环境后整体偏亮，先调曝光（0.6~1.2 是常见区间）再回头微调 environmentIntensity——顺序反了容易在两个旋钮之间来回拉锯。

代码示例 ​

阴影调优台核心代码（即演示实现，逐段注释）：

js
// ① 总开关与类型：r186 默认 PCF；要柔和边缘换 VSM
renderer.shadowMap.enabled = true
renderer.shadowMap.type = THREE.PCFShadowMap

// ② 方向光开影 + 初始参数
const sun = new THREE.DirectionalLight(0xffffff, 2.6)
sun.position.set(5, 7, 4)
sun.castShadow = true
sun.shadow.mapSize.set(1024, 1024)  // 阴影贴图分辨率
sun.shadow.bias = -0.0002           // 治痤疮：深度比较微偏
sun.shadow.normalBias = 0.02        // 治斜面条纹：沿法线偏移采样点
sun.shadow.radius = 4               // PCF 扩散采样 / VSM 模糊半径
scene.add(sun)

// ③ 收紧阴影相机：零显存代价换等效分辨率
function setShadowRange(half) {
  const cam = sun.shadow.camera
  cam.left = -half; cam.right = half
  cam.top = half;   cam.bottom = -half
  cam.near = 1;     cam.far = 25
  cam.updateProjectionMatrix()
}
setShadowRange(6)

// ④ 运行时改 mapSize：必须销毁旧贴图，下一帧才按新尺寸重建
function setMapSize(size) {
  sun.shadow.mapSize.set(size, size)
  if (sun.shadow.map) { sun.shadow.map.dispose(); sun.shadow.map = null }
}

// ⑤ 切换 PCF/VSM：换了着色器分支，所有材质需要重编译
function setShadowType(type) {
  renderer.shadowMap.type = type === 'VSM' ? THREE.VSMShadowMap : THREE.PCFShadowMap
  scene.traverse(o => { if (o.material) o.material.needsUpdate = true })
  if (sun.shadow.map) { sun.shadow.map.dispose(); sun.shadow.map = null }
}

④⑤ 两段是新手最容易漏的"暗坑"：阴影贴图和着色器都是惰性重建的，改了参数不触发重建，画面永远不变。

常见问题解答 ​

Q1：阴影锯齿 / 表面条纹（痤疮）到底调哪个？

分两步：先 normalBias 后 bias。曲面、斜面上的条纹是采样点贴表面太近造成的，normalBias（0.01~0.05 起步）把采样点沿法线推离表面，专治这种；残留的细密条纹再用 bias（-0.0001~-0.001 量级）微调。两个都别拉过头——拉过头阴影就"悬空"了（物体脚下出现缝隙，即 peter-panning）。纯边缘锯齿则靠 mapSize 与收紧相机范围。

Q2：物体走出一定距离阴影就消失，或阴影被齐刷刷裁断？

九成是阴影相机没罩住。方向光的阴影只渲染在 shadow.camera 那个正交盒子里：左右上下超出范围 → 阴影被裁；距离超过 far → 阴影消失。调试神器：scene.add(new THREE.CameraHelper(light.shadow.camera)) 把盒子画出来，罩住所有投影物即可。注意别为了"罩得住"把盒子开太大——那就是 Q1 锯齿的来源，范围与分辨率永远是拉锯战。

Q3：产品展示页该选哪种 toneMapping？

默认 ACESFilmic：高光柔、电影感强，汽车官网几乎都是这个味。两个例外：商品颜色必须和实物严格一致（电商白底图、口红试色）选 Neutral，它最忠实原色；场景里有大量霓虹灯、发光屏、强高光（赛博朋克风）选 AgX，极亮处不会漂成一团白。选完模式记得用 toneMappingExposure 做最后定调。

Q4：LightProbe 和 scene.environment 到底用哪个？

要清晰的镜面倒影（金属、清漆、玻璃）→ scene.environment（PMREM 贴图）；只要柔和的环境底光、或需要多个局部区域各自的环境光（房间内外、驾驶舱）→ LightProbe，它只有 27 个系数、开销几乎为零。两者可以叠加使用，探针补底光、environment 出倒影。

动手小练习 ​

  1. 演示里把 mapSize 降到 256、bias 拉到 0，观察厚板顶面的条纹；然后只调 normalBias 到 0.05 看修复效果，体会它与 bias 的分工。
  2. 打开"相机辅助线"，把阴影相机范围从 14 收到 3，对比阴影边缘锯齿——体会"免费的清晰度"。
  3. 切换到 VSM + radius 拉到 10，观察柔和边缘与角落的漏光（light bleeding）；切回 PCF 比较，想想你的产品页该选哪种。
