14.1 基础入门：IBL 与 HDR 环境贴图 ​

前置提示：本篇属于精通方向扩展内容，建议先完成基础模块 ⑥⑧ 再学习本篇。

核心概念讲解 ​

接桥：给 15.3 的模型展示页换一套 HDR 摄影棚 ​

还记得 15.3 实战：模型展示页 里那行 RoomEnvironment 吗？当时我们用程序化生成的"房间"给 PBR 材质提供反射内容。它够用，但反射出来的永远是那几扇窗、那几根灯管——换个产品就露怯。把它换成一张真实拍摄的 HDR 环境图，只差几行：

js
// 15.3 里的程序化摄影棚
scene.environment = pmrem.fromScene(new RoomEnvironment(), 0.04).texture

// 换成真实 HDR 环境（威尼斯日落）
new RGBELoader().load(HDR_URL, (tex) => {
  tex.mapping = THREE.EquirectangularReflectionMapping
  scene.environment = pmrem.fromEquirectangular(tex).texture
})

金属车漆立刻映出窗外的天空与落日——模型没变、灯光没变，质感却像换了一个渲染器。这就是本章的主角：IBL。

什么是 IBL：光来自整个环境 ​

传统打光是"点光源思维"：往场景里放几盏灯，照亮物体朝向灯的那一面。但真实世界里，物体被整个环境包围着照亮——天空、地面、墙面、窗户，每个方向都有光射过来。

IBL（Image-Based Lighting，基于图像的光照）用一张 360° 全景图代替"一堆灯"：图上每个像素就是一个方向的光源，材质着色时朝各个方向采样这张图，算出漫反射与镜面反射。

这正好解释了 6.1 留下的悬案："为什么 Standard 材质灰蒙蒙？"——金属的质感几乎完全来自反射，没有环境图，金属球就没有可反射的内容，堆多少盏点光都没用。

HDR 与 LDR：动态范围的差距 ​

普通图片（PNG/JPG）是 LDR：每通道 0~255 整数，最亮也只是"白"。真实世界的亮度范围远超于此——太阳表面能比天空亮几千倍。

HDR（高动态范围） 图片用浮点数存亮度，上限几乎不受限：

  • 太阳在图里真的是"超亮的一团"，金属反射它时出现耀眼高光，而不是一个灰色圆斑；
  • 配合色调映射（tone mapping）把物理亮度压回屏幕的 0~1，暗部与高光细节都保得住。
LDR（.jpg/.png）HDR（.hdr/.exr）
通道精度8 bit 整数16/32 bit 浮点
亮度上限1.0（255）几乎无上限
用作环境光暗部缺失、高光发灰光影关系真实
体积小大（1k 约 1~2MB）

RGBELoader 与 .hdr/.exr ​

  • .hdr（Radiance RGBE）：老牌格式，文件相对小，Web 端最常用，配 RGBELoader；
  • .exr（OpenEXR）：影视工业标准，精度更高、体积更大，配 EXRLoader。

两者装的都是**等距柱状投影（equirectangular）**的 2:1 全景图。免费 HDR 资产库推荐 Poly Haven（CC0 可商用，记得选 1k/2k 档位）。

PMREMGenerator：为什么不能直接赋值 ​

PBR 材质采样环境图时有个矛盾：粗糙表面要"模糊版"环境，镜面金属要"清晰版"。PMREMGenerator 就是预处理器——把等距全景图预过滤成一串不同模糊度的 mip 级别，运行时按 roughness 直接取用，又快又稳。

所以规范姿势永远是两步：

js
const pmrem = new THREE.PMREMGenerator(renderer)
scene.environment = pmrem.fromEquirectangular(hdrTex).texture

跳过 PMREM 直接赋值，粗糙反射会闪烁、立方体接缝可能漏出来。一次预处理，全程受益。

scene.environment 与 scene.background 分设 ​

  • scene.environment：光照数据源，不参与画面显示；所有 PBR 材质自动从中取反射与环境光；
  • scene.background：观众看到的背景，可以是纯色、贴图或同一张环境图。

两者互相独立。产品页的经典搭配是"HDR 供光照 + 压暗或纯色的背景"，让注意力留在商品上。r186 还提供 scene.environmentIntensity / backgroundIntensity / environmentRotation / backgroundRotation 四个微调旋钮，本篇与 14.3 都会用到。

代码示例 ​

完整流程：加载 HDR → PMREM 预过滤 → 分设 environment 与 background → 色调映射防过曝。

js
import * as THREE from 'three'
import { RGBELoader } from 'three/addons/loaders/RGBELoader.js'

// ① 渲染器：HDR 光照必须配色调映射，否则大面积过曝
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.toneMapping = THREE.ACESFilmicToneMapping  // 电影级高光 roll-off
renderer.toneMappingExposure = 1.0                  // 曝光旋钮，随时可调

// ② PMREM 预处理器：每个 renderer 建一个即可复用
const pmrem = new THREE.PMREMGenerator(renderer)

// ③ RGBELoader 加载等距柱状 HDR（1k 约 1.4MB，开发演示足够）
const HDR_URL = 'https://cdn.jsdelivr.net/gh/mrdoob/three.js@r186/examples/textures/equirectangular/venice_sunset_1k.hdr'
new RGBELoader().load(HDR_URL, (hdrTex) => {

  // ④ 标记投影方式：这是一张 2:1 的等距柱状全景图
  hdrTex.mapping = THREE.EquirectangularReflectionMapping

  // ⑤ 光照：预过滤后赋给 environment，全场景 PBR 材质自动生效
  scene.environment = pmrem.fromEquirectangular(hdrTex).texture

  // ⑥ 背景：用原始 HDR 图（要清晰），压暗一点突出主体
  scene.background = hdrTex
  scene.backgroundIntensity = 0.55

  // ⑦ 可选微调：整体增强/减弱环境光对材质的作用
  scene.environmentIntensity = 1.0
})

要点回顾：

  1. environment 用 PMREM 后的纹理，background 用原始 HDR——前者要模糊 mip 供粗糙表面采样，后者要清晰画面给观众看；
  2. 原图还被 background 引用时不要 hdrTex.dispose()；若 HDR 只作光照，生成 PMREM 后即可 dispose 原图省显存；
  3. CDN 不可达或想离线时，pmrem.fromScene(new RoomEnvironment(), 0.04) 是最快的程序化替代（6.3 与 15.3 都在用）。

常见问题解答 ​

Q1：加载 HDR 后整个场景过亮/过曝，白成一片？

HDR 带来真实物理亮度，不做"洗印"就会冲爆屏幕。三步排查：① 确认 renderer.toneMapping 设为 ACESFilmicToneMapping（或其它非 None 模式）；② 调 renderer.toneMappingExposure，HDR 场景常用 0.6~1.2；③ 背景太抢戏就降 scene.backgroundIntensity，材质整体太亮就降 scene.environmentIntensity——两个强度旋钮互不影响，分开调。

Q2：PMREM 到底是什么？为什么不直接把 HDR 赋给 scene.environment？

PMREM（Pre-filtered Mipmap Radiance Environment Map）是"预过滤环境贴图"：把全景图按不同粗糙度预先模糊成一串 mip 级别。材质着色时按自己的 roughness 取对应模糊度——粗糙表面取糊的、镜面取清晰的，一次采样搞定。直接赋原图等于让每个像素现场做几百次采样平均，既慢又闪。所以记住口诀：光照过 PMREM，背景用原图。

Q3：HDR 文件太大，4k 一张十几 MB 怎么办？

三个手段按序尝试：① 降分辨率——作光照用 1k 完全够（模糊后根本看不出区别），要当清晰背景再上 2k，4k 几乎没必要；② 运行时转换——pmrem.fromEquirectangular() 后 hdrTex.dispose() 丢弃原图，只留小巧的 PMREM 纹理；③ 干脆不加载——RoomEnvironment 这类程序化环境零下载量。Poly Haven 下载页右侧就能选 1k/2k 档位。

Q4：赋了 scene.environment 却看不出变化？

按顺序查：① 材质是不是 MeshStandardMaterial/MeshPhysicalMaterial——Basic/Lambert 不吃环境贴图；② 控制台有没有 404 或加载报错（CDN 网络问题最常见）；③ 是不是 toneMapping 没开导致差异被过曝糊掉了。另外 environment 对金属材质影响最戏剧化，先拿 metalness=1 的球验证最直观。

动手小练习 ​

  1. 演示里把背景切成"纯色"、环境保持 HDR，体会"光照没变、氛围变了"——environment 与 background 是两条独立管线。
  2. 把"环境强度"从 0 慢慢拉到 2，盯着非金属那一排：环境光对漫反射同样有贡献，不只是金属的专利。
  3. 在 RoomEnvironment 与 HDR 之间来回切换，同时把曝光从 1.0 调到 0.7，感受不同环境图带来的"色温"与反差差异——这就是产品页选环境图时的手感。
