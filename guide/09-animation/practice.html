9.3 实战案例：时间轴播放器（拖拽/暂停/速度） ​

核心概念讲解 ​

掌握了 Mixer，就能做一个像视频播放器一样的动画时间轴：进度条拖拽、播放/暂停、变速、循环区间。核心是理解 action 的时间是可以被外部直接设置的：

js
action.paused = true        // 暂停（暂停后可以手动拨 time）
action.time = t             // 直接跳到第 t 秒
mixer.update(0)             // 用 0 delta 强制把当前 time 的姿态写入对象

为什么 setTime 后要 mixer.update(0) ​

改 action.time 只是改了内部时钟，物体姿态要等下一次 update 才刷新。手动 seek 后立刻 mixer.update(0)，可以不推进时间却强制重算当前姿态，实现"拖到哪显示到哪"。

术语解释：

  • Scrubbing（刮擦/拖拽预览）：像视频剪辑软件一样拖动时间轴即时预览任意时刻画面。
  • 时间归一化：进度条 0~100% 与 clip 的 0~duration 秒互转。

UI 与动画循环解耦 ​

进度条 input 事件只改 action.time；动画循环只读 action.time 刷新 UI。为避免"循环写进度条→又触发 input→抖动"，只在用户没有正在拖拽时由循环更新进度条数值。

代码示例 ​

一段"小球绕轨道运动 + 颜色渐变 + 门开合"的合成动画，配上完整播放控件：

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0b0e14)
const camera = new THREE.PerspectiveCamera(45, innerWidth / innerHeight, 0.1, 100)
camera.position.set(0, 3, 6)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
document.getElementById('app').appendChild(renderer.domElement)
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true
controls.target.set(0, 0.5, 0)

scene.add(new THREE.HemisphereLight(0xbfd9ff, 0x222222, 0.8))
const dir = new THREE.DirectionalLight(0xffffff, 1.6)
dir.position.set(3, 5, 4)
scene.add(dir)
scene.add(new THREE.GridHelper(8, 16, 0x334155, 0x1e293b))

// 运动小球
const ball = new THREE.Mesh(
  new THREE.SphereGeometry(0.3, 32, 24),
  new THREE.MeshStandardMaterial({ color: 0x60a5fa })
)
ball.position.y = 0.3
scene.add(ball)

// 绕圈轨道
const orbitPts = []
for (let i = 0; i <= 128; i++) {
  const a = (i / 128) * Math.PI * 2
  orbitPts.push(new THREE.Vector3(Math.cos(a) * 2, 0.3, Math.sin(a) * 2))
}
scene.add(new THREE.Line(
  new THREE.BufferGeometry().setFromPoints(orbitPts),
  new THREE.LineBasicMaterial({ color: 0x334155 })
))

// 一扇绕 Y 开合的门（pivot 在侧边）
const doorPivot = new THREE.Group()
doorPivot.position.set(-2, 0, -2)
const door = new THREE.Mesh(
  new THREE.BoxGeometry(1.4, 1.8, 0.08),
  new THREE.MeshStandardMaterial({ color: 0xf59e0b })
)
door.position.set(0.7, 0.9, 0)
doorPivot.add(door)
scene.add(doorPivot)

/* ---------- 构造 4 秒 clip ---------- */
const T = 4
const times = [0, T / 2, T]
// 小球沿圆周：用两段轨道写若干位置点（这里用角度算位置）
const posValues = []
const posTimes = []
for (let i = 0; i <= 8; i++) {
  const t = (i / 8) * T
  const a = (i / 8) * Math.PI * 2
  posTimes.push(t)
  posValues.push(Math.cos(a) * 2, 0.3, Math.sin(a) * 2)
}
const ballClip = new THREE.AnimationClip('orbit', T, [
  new THREE.VectorKeyframeTrack('.position', posTimes, posValues),
  new THREE.ColorKeyframeTrack('.material.color',
    [0, T / 2, T],
    [0.38, 0.65, 0.98,  0.96, 0.62, 0.04,  0.38, 0.65, 0.98])
])

// 门：0~2s 打开，2~4s 关上（四元数绕 Y）
const q = a => new THREE.Quaternion().setFromAxisAngle(new THREE.Vector3(0, 1, 0), a).toArray()
const doorClip = new THREE.AnimationClip('door', T, [
  new THREE.QuaternionKeyframeTrack('.quaternion',
    [0, T / 2, T], [...q(0), ...q(-Math.PI / 2), ...q(0)])
])

const mixer = new THREE.AnimationMixer(scene)
const ballAction = mixer.clipAction(ballClip).play()
const doorAction = mixer.clipAction(doorClip).play()
ballAction.clampWhenFinished = false
doorAction.clampWhenFinished = false

/* ---------- 播放器 UI ---------- */
const playBtn = document.getElementById('play')
const slider = document.getElementById('timeline')
const timeLabel = document.getElementById('time')
const speedSel = document.getElementById('speed')
let scrubbing = false

playBtn.addEventListener('click', () => {
  if (ballAction.paused) {
    ballAction.paused = doorAction.paused = false
    playBtn.textContent = '⏸'
  } else {
    ballAction.paused = doorAction.paused = true
    playBtn.textContent = '▶'
  }
})

// 拖拽进度条：暂停推进，直接写 time 并用 update(0) 刷新姿态
slider.addEventListener('pointerdown', () => { scrubbing = true })
slider.addEventListener('pointerup', () => { scrubbing = false })
slider.addEventListener('input', () => {
  const t = (slider.value / 100) * T
  ballAction.time = doorAction.time = t
  mixer.update(0)
  timeLabel.textContent = t.toFixed(2)
})

speedSel.addEventListener('change', () => {
  mixer.timeScale = parseFloat(speedSel.value)
})

const clock = new THREE.Timer()

clock.connect(document) // r183 起 Clock 已弃用，改用 Timer
renderer.setAnimationLoop(() => {
  clock.update() // 每帧先 update，再读取
  const dt = clock.getDelta()
  if (!ballAction.paused) mixer.update(dt)
  controls.update()
  renderer.render(scene, camera)

  // 用户没在拖时，由播放进度反向同步进度条
  if (!scrubbing) {
    const t = ballAction.time % T
    slider.value = (t / T) * 100
    timeLabel.textContent = t.toFixed(2)
  }
})

配套的 HTML 控件（放在 body 底部）：

html
<div style="position:fixed;left:50%;bottom:14px;transform:translateX(-50%);
  display:flex;align-items:center;gap:10px;background:rgba(11,14,20,.85);
  padding:8px 14px;border-radius:10px;z-index:10">
  <button id="play" style="...">⏸</button>
  <input id="timeline" type="range" min="0" max="100" value="0" style="width:280px">
  <span id="time" style="color:#cbd5e1;font:12px monospace;width:42px">0.00</span>
  <select id="speed">
    <option value="0.25">0.25x</option>
    <option value="0.5">0.5x</option>
    <option value="1" selected>1x</option>
    <option value="2">2x</option>
  </select>
</div>

常见问题解答 ​

Q1：拖动进度条时画面不更新，松手才更新？

改完 action.time 后立即调用 mixer.update(0)，用零增量强制把当前时刻姿态写入对象。只改 time 不 update，要等下一帧播放循环才刷新。

Q2：为什么循环更新进度条会和拖拽打架（抖动/回弹）？

用一个 scrubbing 标志：pointerdown 置 true（此时循环不写 slider.value），pointerup 置 false。播放循环只在非拖拽状态反向同步进度条，避免互相触发。

Q3：多个对象的动画怎么保证严格同步？

让它们共用同一个 mixer，并在一次 mixer.update(dt) 中推进——所有 action 共享 mixer 的时间基准。示例里小球和门就是同一 mixer、同一 time，天然同步。

动手小练习 ​

  1. 加"A-B 区间循环"：两个输入框指定起止秒数，action 到达 B 点自动跳回 A。
  2. 加"逐帧前进/后退"按钮：每次把 time 移动 1/30 秒。
  3. 让速度为负时播放按钮图标变成"倒带"，并正确处理循环边界。
