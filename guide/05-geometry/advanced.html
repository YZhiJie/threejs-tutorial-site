5.2 进阶应用：自定义几何体与顶点属性 ​

核心概念讲解 ​

内置几何体不够用时（金字塔、自定义地形、程序化建筑），可以直接填数组创建 BufferGeometry。核心流程只有三步：

  1. 准备一个扁平的 positions 数组：每个顶点 3 个数 (x,y,z)
  2. 用 Float32BufferAttribute 包成属性并 setAttribute('position', ...)
  3. 调用 computeVertexNormals() 自动算法线（否则光照不对）

为什么侧面要"每面独立的 3 个顶点" ​

一个立方体其实只有 8 个角，但如果只写 8 个顶点共享给相邻面，相邻面会被强制共享法线，棱角就会被平滑成圆角。想要硬棱，就让每个三角形拥有自己独立的 3 个顶点（立方体因此需要 36 个顶点、12 个三角形）。

术语解释：索引几何体（indexed geometry） 用一个 index 数组让多个三角形复用同一批顶点，省内存且利于平滑；非索引几何体 每面独立顶点，方便做硬棱/平面着色。内置几何体默认是索引的。

顶点色 ​

给每个顶点加一个 color 属性，材质开启 vertexColors: true，GPU 会在三角形内部对顶点颜色插值，形成渐变。数据结构与 position 一样是每顶点 3 个数（r,g,b，范围 0~1）。

代码示例 ​

下面手写一个四棱锥（金字塔）：4 个侧面 = 12 个顶点，每面一种顶点色：

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import GUI from 'three/addons/libs/lil-gui.module.min.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0b0e14)
const camera = new THREE.PerspectiveCamera(45, innerWidth / innerHeight, 0.1, 100)
camera.position.set(2.4, 1.8, 3.4)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
document.getElementById('app').appendChild(renderer.domElement)
new OrbitControls(camera, renderer.domElement).enableDamping = true
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true

scene.add(new THREE.HemisphereLight(0xbfd9ff, 0x222222, 0.7))
const dir = new THREE.DirectionalLight(0xffffff, 2)
dir.position.set(3, 5, 4)
scene.add(dir)
scene.add(new THREE.AxesHelper(1.6))
scene.add(new THREE.GridHelper(6, 12, 0x334155, 0x1e293b))

/* 金字塔：底面 4 角 + 1 顶点。4 个侧面，每面 3 顶点（硬棱） */
const apex = [0, 1.1, 0]
const corners = [
  [-0.8, 0, -0.8], [0.8, 0, -0.8], [0.8, 0, 0.8], [-0.8, 0, 0.8]
]
// 每个侧面 = [底角1, 底角2, 顶点]；顶点顺序决定面朝向（绕序）
const faces = [
  [corners[0], corners[1], apex],
  [corners[1], corners[2], apex],
  [corners[2], corners[3], apex],
  [corners[3], corners[0], apex]
]
const faceColors = [
  [0.90, 0.35, 0.35],  // 红
  [0.35, 0.70, 0.90],  // 蓝
  [0.45, 0.80, 0.45],  // 绿
  [0.95, 0.75, 0.30]   // 黄
]

const positions = []
const colors = []
faces.forEach((face, fi) => {
  face.forEach(p => {
    positions.push(p[0], p[1], p[2])
    colors.push(...faceColors[fi])     // 同一面 3 个顶点同色 → 硬棱
  })
})

const geometry = new THREE.BufferGeometry()
// 每 3 个数一个顶点
geometry.setAttribute('position', new THREE.Float32BufferAttribute(positions, 3))
geometry.setAttribute('color', new THREE.Float32BufferAttribute(colors, 3))
geometry.computeVertexNormals()        // 由位置自动算法线，光照才正确
geometry.computeBoundingSphere()       // 视锥剔除需要包围球

const material = new THREE.MeshStandardMaterial({
  vertexColors: true,                  // 启用 color 属性
  roughness: 0.4,
  side: THREE.DoubleSide               // 不加底面，双面渲染避免从背面看穿
})
const pyramid = new THREE.Mesh(geometry, material)
scene.add(pyramid)

// 叠加白色结构线，便于观察三角形构成
const wire = new THREE.LineSegments(
  new THREE.WireframeGeometry(geometry),
  new THREE.LineBasicMaterial({ color: 0xffffff, transparent: true, opacity: 0.25 })
)
pyramid.add(wire)

const params = { wireframe: false, overlay: true, spin: true }
const gui = new GUI({ title: '几何体属性' })
gui.add(params, 'wireframe').name('实体线框化').onChange(v => material.wireframe = v)
gui.add(params, 'overlay').name('白色结构线').onChange(v => wire.visible = v)
gui.add(params, 'spin').name('旋转')

renderer.setAnimationLoop(() => {
  if (params.spin) pyramid.rotation.y += 0.006
  controls.update()
  renderer.render(scene, camera)
})

常见问题解答 ​

Q1：为什么我写的三角形从正面看不见、从背面才看见？

三角形有绕序（winding order）：逆时针为正面。顶点顺序写反会导致面朝向反方向，而材质默认 side: FrontSide 只渲染正面。可先改成 DoubleSide 确认，再调整三个顶点顺序。

Q2：忘了 computeVertexNormals 会怎样？

法线默认是 (0,0,0)，受光计算结果全黑或异常。除非你要精确手工控制法线，否则填完 position 后养成调 computeVertexNormals() 的习惯。

Q3：Float32BufferAttribute 的数据为什么用 TypedArray？

GPU 需要连续、定长的二进制内存，普通 JS 数组无法直接上传。Float32Array 以 4 字节浮点连续存储，Three.js 会原样送进 GPU 缓冲，这也是为什么属性数组必须"扁平"（不能嵌套数组）。
