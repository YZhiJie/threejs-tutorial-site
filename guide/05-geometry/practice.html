5.3 实战案例：顶点形变动画 ​

核心概念讲解 ​

旗帜飘动、水面起伏、地形滚动——这些动画不移动 Mesh、不换几何体，而是每帧直接改写 position 属性里每个顶点的坐标。这是 GPU 顶点动画思想的 CPU 版入门。

逐帧更新顶点的三步 ​

  1. 修改 position 属性里的坐标值（getX/setY 或直接写数组）
  2. 标记 position.needsUpdate = true，Three.js 才会把新数据重新上传 GPU
  3. 调用 computeVertexNormals() 重算法线，否则光照不会随起伏变化

注意：逐顶点 CPU 动画适合几千到一两万顶点。顶点数再多（十万级）应改用 GPU 顶点着色器（在 GLSL/TSL 里形变），CPU 改数组会成为瓶颈。

波形数学 ​

最简单的波浪就是正弦函数：

y = amplitude · sin(x · k + t · speed)
其中 k = 2π / wavelength（波数，控制波长）

叠加两个不同方向、不同相位的正弦波，就能得到更自然的起伏；再用顶点高度映射颜色（低蓝、中青、高白），水面的视觉信息就完整了。

代码示例 ​

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import GUI from 'three/addons/libs/lil-gui.module.min.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0b0e14)
const camera = new THREE.PerspectiveCamera(45, innerWidth / innerHeight, 0.1, 100)
camera.position.set(4.2, 3.2, 4.8)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
document.getElementById('app').appendChild(renderer.domElement)
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true

scene.add(new THREE.HemisphereLight(0xbfd9ff, 0x182030, 1))
const dir = new THREE.DirectionalLight(0xffffff, 2)
dir.position.set(3, 6, 4)
scene.add(dir)

// 细分足够多的平面才有平滑波浪：96×96 = 9409 个顶点
const SIZE = 6
const SEG = 96
const geometry = new THREE.PlaneGeometry(SIZE, SIZE, SEG, SEG)
geometry.rotateX(-Math.PI / 2)        // 默认平面在 XY，转到 XZ 水平

// 逐顶点颜色缓冲
const colors = new Float32Array(geometry.attributes.position.count * 3)
geometry.setAttribute('color', new THREE.BufferAttribute(colors, 3))

const material = new THREE.MeshStandardMaterial({
  vertexColors: true, roughness: 0.35, metalness: 0.25, side: THREE.DoubleSide
})
const wave = new THREE.Mesh(geometry, material)
scene.add(wave)

const params = { amplitude: 0.55, wavelength: 3.2, speed: 1.6, secondary: 0.35, wireframe: false }
const gui = new GUI({ title: '波浪参数' })
gui.add(params, 'amplitude', 0, 1.5, 0.02).name('波幅')
gui.add(params, 'wavelength', 0.8, 8, 0.1).name('波长')
gui.add(params, 'speed', 0, 5, 0.05).name('波速')
gui.add(params, 'secondary', 0, 1, 0.05).name('副波强度')
gui.add(params, 'wireframe').name('线框').onChange(v => material.wireframe = v)

const pos = geometry.attributes.position
const colAttr = geometry.attributes.color
const low = new THREE.Color(0x1d4ed8)   // 谷底深蓝
const mid = new THREE.Color(0x22d3ee)   // 中间青
const high = new THREE.Color(0xf0f9ff)  // 浪尖近白
const tmp = new THREE.Color()

function updateWave(t) {
  const k = Math.PI * 2 / params.wavelength
  for (let i = 0; i < pos.count; i++) {
    const x = pos.getX(i)
    const z = pos.getZ(i)
    // 两个方向的正弦叠加：主波沿 X，副波沿 Z
    const h1 = Math.sin(x * k + t * params.speed)
    const h2 = Math.sin(z * k * 1.35 - t * params.speed * 1.25)
    const y = (h1 + h2 * params.secondary) * params.amplitude
    pos.setY(i, y)

    // 高度归一化到 0~1，在 低→中→高 三色间分段插值
    const n = THREE.MathUtils.clamp(
      (y + params.amplitude * 1.3) / (params.amplitude * 2.6), 0, 1)
    if (n < 0.5) tmp.copy(low).lerp(mid, n * 2)
    else tmp.copy(mid).lerp(high, (n - 0.5) * 2)
    colAttr.setXYZ(i, tmp.r, tmp.g, tmp.b)
  }
  pos.needsUpdate = true          // 关键！通知 GPU 重新上传位置
  colAttr.needsUpdate = true
  geometry.computeVertexNormals() // 重算法线，光照随起伏变化
}

const clock = new THREE.Timer()

clock.connect(document) // r183 起 Clock 已弃用，改用 Timer
renderer.setAnimationLoop(() => {
  clock.update() // 每帧先 update，再读取
  updateWave(clock.getElapsed())
  controls.update()
  renderer.render(scene, camera)
})

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight
  camera.updateProjectionMatrix()
  renderer.setSize(innerWidth, innerHeight)
})

常见问题解答 ​

Q1：改了顶点坐标但画面不动？

99% 是忘了 position.needsUpdate = true。Three.js 只在首次和你显式标记后上传缓冲；不标记，GPU 仍用旧数据。

Q2：波浪动了但光照不对、高光不跟着走？

顶点位移后法线还是旧的。每帧调用 geometry.computeVertexNormals() 即可（一万顶点级别开销可接受）。更高要求可用 computeVertexNormals 的替代：只在形变较显著时重算，或着色器里算法线。

Q3：顶点一多就卡，怎么优化？

三招：① 降低 SEG 分段；② 把形变挪进顶点着色器（GLSL/TSL），CPU 完全不碰数组；③ 不需要每帧重算颜色时，把颜色计算移到初始化或材质端。

动手小练习 ​

  1. 把波形换成 Gerstner 波（波峰更尖锐、波谷更平缓），做出更像海浪的形状。
  2. 加一艘"小船"（小盒子），让它的 y 位置与倾斜跟随波浪高度与斜率。
  3. 用同样的顶点更新机制做一面"飘动的旗帜"（平面 + 仅一个方向的正弦 + 固定一边）。
