2.2 进阶应用：层级变换、矩阵与雾 ​

核心概念讲解 ​

父子层级：变换如何传递 ​

Three.js 每个 Object3D 内部维护三部分矩阵：

  • matrix：局部矩阵（由 position/rotation/scale 组合而成）
  • matrixWorld：世界矩阵 = 所有祖先的 matrix 连乘 × 自己的 matrix
  • 默认 matrixAutoUpdate = true，每帧自动重算；手动设为 false 后改完变换要调 updateMatrix()

层级带来的两个关键效果：

  1. 父节点平移/旋转/缩放，子节点整体跟随（汽车车身动，轮子跟着走）
  2. 子节点同时可以有自己的局部运动（轮子自己还能转）

术语解释：复合变换的顺序是 缩放 → 旋转 → 平移（TRS）。Three.js 用 position、quaternion、scale 三个量合成局部矩阵，避免直接让你操作矩阵元素。

欧拉角与四元数 ​

  • rotation 是欧拉角（XYZ 三个角度），直观但存在万向节死锁（Gimbal Lock）
  • quaternion 是四元数，插值平滑、无死锁。做关键帧动画、相机朝向时优先用四元数
  • 两者会自动同步，改一个另一个跟着更新

雾 Fog：廉价的纵深感 ​

  • new THREE.Fog(color, near, far)：线性雾，距离 near 开始变淡、far 完全融入背景
  • new THREE.FogExp2(color, density)：指数雾，浓度随距离指数增长，更自然
  • 雾的颜色必须和背景色一致，否则远处会出现"灰幕"

代码示例 ​

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import GUI from 'three/addons/libs/lil-gui.module.min.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0b0e14)
scene.fog = new THREE.Fog(0x0b0e14, 6, 22)   // 线性雾：颜色与背景一致

const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100)
camera.position.set(0, 3.2, 7.5)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
document.getElementById('app').appendChild(renderer.domElement)
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true

scene.add(new THREE.AmbientLight(0xffffff, 0.6))
const light = new THREE.DirectionalLight(0xffffff, 1.6)
light.position.set(4, 6, 3)
scene.add(light)

/* ---------- 父节点 Group ---------- */
const parent = new THREE.Group()
scene.add(parent)

const parentBall = new THREE.Mesh(
  new THREE.SphereGeometry(0.9, 40, 30),
  new THREE.MeshStandardMaterial({ color: 0x3b82f6, roughness: 0.35 })
)
parent.add(parentBall)
parent.add(new THREE.AxesHelper(1.8))

/* ---------- 子节点：放在父节点局部坐标 x=2 处 ---------- */
const child = new THREE.Mesh(
  new THREE.SphereGeometry(0.35, 24, 18),
  new THREE.MeshStandardMaterial({ color: 0xf59e0b, roughness: 0.3 })
)
child.position.x = 2
parent.add(child)

// 轨道圈：在父局部空间画一个半径 2 的圆，子球沿它公转
const pts = []
for (let i = 0; i <= 128; i++) {
  const a = (i / 128) * Math.PI * 2
  pts.push(new THREE.Vector3(Math.cos(a) * 2, 0, Math.sin(a) * 2))
}
parent.add(new THREE.Line(
  new THREE.BufferGeometry().setFromPoints(pts),
  new THREE.LineBasicMaterial({ color: 0x475569 })
))

// 远处一排柱子：用来直观看到"远处被雾吞掉"
for (let i = 0; i < 10; i++) {
  const pillar = new THREE.Mesh(
    new THREE.BoxGeometry(0.5, 1, 0.5),
    new THREE.MeshStandardMaterial({ color: 0x64748b })
  )
  pillar.position.set(0, 0.5, -4 - i * 1.6)
  scene.add(pillar)
}

const params = { parentSpin: true, parentSpeed: 0.6, childOrbit: true, childSpeed: 2.2,
                 fog: true, near: 6, far: 22 }
const gui = new GUI({ title: '层级与雾' })
gui.add(params, 'parentSpin').name('父节点自转')
gui.add(params, 'parentSpeed', 0, 3, 0.05)
gui.add(params, 'childOrbit').name('子节点公转')
gui.add(params, 'childSpeed', 0, 6, 0.1)
const fogF = gui.addFolder('雾')
fogF.add(params, 'fog').name('启用')
fogF.add(params, 'near', 0, 20, 0.5).onChange(v => scene.fog.near = v)
fogF.add(params, 'far', 5, 40, 0.5).onChange(v => scene.fog.far = v)

const clock = new THREE.Timer()

clock.connect(document) // r183 起 Clock 已弃用，改用 Timer
renderer.setAnimationLoop(() => {
  clock.update() // 每帧先 update，再读取
  const dt = clock.getDelta()
  if (params.parentSpin) parent.rotation.y += dt * params.parentSpeed  // 父转 → 子整体跟着转
  if (params.childOrbit) {
    // 子节点在"父局部空间"里做圆周运动
    const a = Math.atan2(child.position.z, child.position.x) + dt * params.childSpeed
    child.position.set(Math.cos(a) * 2, 0, Math.sin(a) * 2)
  }
  scene.fog = params.fog ? new THREE.Fog(0x0b0e14, params.near, params.far) : null
  controls.update()
  renderer.render(scene, camera)
})

常见问题解答 ​

Q1：子物体怎么取得"去掉父节点影响"的方向？

用 mesh.getWorldPosition(vec3) / getWorldQuaternion(quat)，它们沿父链累乘得到世界值。反向变换（世界→局部）用 parent.worldToLocal(vec3)。

Q2：为什么开了雾，材质像蒙了一层灰？

雾色和背景色不一致。雾是把物体颜色向 fog.color 插值，如果背景是深蓝而雾是白色，远处就像挂了灰幕。把两者设成同一个颜色。

Q3：matrixAutoUpdate 什么时候该关？

场景里有大量（数千个）物体、且大部分静止时，关闭自动更新并在变换后手动 updateMatrix() 能省 CPU。动态物体多的普通场景保持默认即可，收益不大。

动手小练习 ​

  1. 给子球再挂一个"卫星"小球，形成三层结构，验证卫星同时继承父球与 Group 的旋转。
  2. 把雾换成 FogExp2，从 density=0.01 开始调，对比线性雾与指数雾的衰减手感。
  3. 打印 parent.matrixWorld 与 child.matrixWorld，观察父节点旋转后两者矩阵的关系。
