2.3 实战案例：太阳系层级模型 ​

核心概念讲解 ​

太阳系是理解"场景图层级"最经典的案例。真实轨道力学很复杂，但我们只需要用三层 Group 嵌套就能做出视觉正确的公转+自转：

为什么要"公转节点"这个中间层 ​

如果直接让地球绕太阳转，同时地球还要自转，两套旋转会互相干扰。引入一个不含任何几何体的 Group 作为轨道节点：

  • 公转 = 旋转这个 Group（地球挂在它偏离中心的位置上）
  • 自转 = 旋转地球自己
  • 月球轨道节点再挂在地球上，自然同时继承"地球绕日"与"地球自转"

自发光与照亮别人是两回事 ​

  • material.emissive 只让材质自己"看起来发光"，不会照亮别的物体
  • 要真正照亮场景，必须在太阳位置放一盏 PointLight
  • r155+ 点光源遵循物理衰减（decay 默认 2），intensity 需要较大数值（示例用 260）

代码示例 ​

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import GUI from 'three/addons/libs/lil-gui.module.min.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x05060a)
const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 200)
camera.position.set(0, 7, 13)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
document.getElementById('app').appendChild(renderer.domElement)
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true
controls.maxPolarAngle = Math.PI / 2 + 0.25

scene.add(new THREE.AmbientLight(0xffffff, 0.18))
// 太阳处的点光源：r186 物理光照，decay=2 时需要大 intensity
const sunLight = new THREE.PointLight(0xfff2c4, 260, 0, 2)
scene.add(sunLight)

// 工具函数：画一条圆形轨道线（极坐标采样 160 个点连成 Line）
function makeOrbit(radius, color = 0x334155) {
  const pts = []
  for (let i = 0; i <= 160; i++) {
    const a = (i / 160) * Math.PI * 2
    pts.push(new THREE.Vector3(Math.cos(a) * radius, 0, Math.sin(a) * radius))
  }
  return new THREE.Line(
    new THREE.BufferGeometry().setFromPoints(pts),
    new THREE.LineBasicMaterial({ color, transparent: true, opacity: 0.6 })
  )
}

/* ---------- 第 1 层：太阳（自转 + 自发光材质）---------- */
const sun = new THREE.Mesh(
  new THREE.SphereGeometry(1.4, 48, 32),
  new THREE.MeshStandardMaterial({
    color: 0xffb703, emissive: 0xffb703, emissiveIntensity: 1.2, roughness: 1
  })
)
scene.add(sun)

/* ---------- 第 2 层：地球公转节点（空 Group）---------- */
const earthOrbit = new THREE.Group()
scene.add(earthOrbit)
scene.add(makeOrbit(5))

const earth = new THREE.Mesh(
  new THREE.SphereGeometry(0.55, 40, 28),
  new THREE.MeshStandardMaterial({ color: 0x2f80ed, roughness: 0.7 })
)
earth.position.x = 5                 // 偏离公转节点中心 5 单位
earthOrbit.add(earth)

/* ---------- 第 3 层：月球公转节点（挂在地球上！）---------- */
const moonOrbit = new THREE.Group()
earth.add(moonOrbit)

const moon = new THREE.Mesh(
  new THREE.SphereGeometry(0.16, 24, 16),
  new THREE.MeshStandardMaterial({ color: 0xcbd5e1, roughness: 0.9 })
)
moon.position.x = 1.1
moonOrbit.add(moon)
earth.add(makeOrbit(1.1, 0x475569))  // 月球轨道线挂在地球上，自然跟随

/* ---------- 星空背景（球面上的随机点云）---------- */
const starCount = 1200
const starPos = new Float32Array(starCount * 3)
for (let i = 0; i < starCount; i++) {
  const r = 60 + Math.random() * 40
  const theta = Math.random() * Math.PI * 2
  const phi = Math.acos(2 * Math.random() - 1)   // 球面均匀分布
  starPos[i*3]   = r * Math.sin(phi) * Math.cos(theta)
  starPos[i*3+1] = r * Math.cos(phi)
  starPos[i*3+2] = r * Math.sin(phi) * Math.sin(theta)
}
const starGeo = new THREE.BufferGeometry()
starGeo.setAttribute('position', new THREE.BufferAttribute(starPos, 3))
const stars = new THREE.Points(starGeo,
  new THREE.PointsMaterial({ color: 0xffffff, size: 0.18, sizeAttenuation: true }))
scene.add(stars)

/* ---------- 时间驱动 ---------- */
const params = { timeScale: 1, showOrbits: true }
const gui = new GUI({ title: '太阳系' })
gui.add(params, 'timeScale', 0, 5, 0.05).name('时间流速')
gui.add(params, 'showOrbits').name('轨道线').onChange(v =>
  scene.traverse(o => { if (o.isLine) o.visible = v }))

const clock = new THREE.Timer()

clock.connect(document) // r183 起 Clock 已弃用，改用 Timer
renderer.setAnimationLoop(() => {
  // 所有角速度都乘 dt*timeScale：与帧率解耦，且可整体变速
  clock.update() // 每帧先 update，再读取
  const dt = clock.getDelta() * params.timeScale
  sun.rotation.y += dt * 0.25
  earthOrbit.rotation.y += dt * 0.5    // 公转：转的是节点
  earth.rotation.y += dt * 1.6         // 自转：转的是地球自己
  moonOrbit.rotation.y += dt * 2.2     // 月球公转（已随地球节点移动）
  controls.update()
  renderer.render(scene, camera)
})

常见问题解答 ​

Q1：为什么地球的位置我写的是 (5,0,0)，它却会绕圈？

(5,0,0) 是相对 earthOrbit 这个父 Group 的局部坐标。每帧旋转 earthOrbit，父节点的坐标系整体转动，局部 x=5 的点就在世界空间里画圆了。

Q2：太阳这么亮，为什么行星背面还是黑的？

PointLight 从太阳位置向外照，行星朝太阳的一面亮、背面暗是正确的。补一点点低强度 AmbientLight（示例 0.18）只是为了让背面不全黑、教学画面更友好。

Q3：轨道圈为什么有时候转到侧面就看不见了？

Line 默认不受雾和光照影响，但它是无限细的线，在某些角度与视线平行时会因光栅化而"消失"。需要稳定可见可改用细 TubeGeometry，或把 material 的 depthTest 设为 false。

动手小练习 ​

  1. 再加一颗"火星"：新的公转节点 + 轨道半径 7 + 红色星球与不同公转速度。
  2. 给地球加 23.4° 倾角（earth.rotation.z 配合一个外层 Group，避免和自转轴冲突）。
  3. 给月球轨道加椭圆度（让 moon.position 沿椭圆而非正圆运动）。
