2.1 基础入门：场景图与 3D 坐标系统 ​

核心概念讲解 ​

场景图（Scene Graph） ​

Scene 不是一个"画图的画布"，而是一棵树：scene 是根，每个 Mesh、Group、Light、Camera 都是树上的节点。Three.js 渲染时从根出发遍历整棵树，把每个节点的局部变换累乘成世界矩阵，再决定怎么画。

术语解释：

  • 场景图：用父子层级组织 3D 对象的数据结构，父节点的位移/旋转/缩放会传递给所有子孙。
  • 局部坐标：相对父节点的坐标，mesh.position 存的就是它。
  • 世界坐标：相对场景根 (0,0,0) 的绝对坐标，用 mesh.getWorldPosition(v) 读取。

Three.js 的右手坐标系 ​

  • 红轴 +X 向右、绿轴 +Y 向上、蓝轴 +Z 朝向屏幕外（前方）
  • 判断旋转正方向：右手大拇指指向某轴正方向，四指弯曲方向就是绕该轴的正向旋转

Object3D：一切节点的共同基类 ​

Scene、Mesh、Group、Light、Camera 都继承自 Object3D，所以它们都有这五个通用属性：position、rotation（欧拉角）、scale、quaternion、visible，以及 add() / remove() / traverse() 方法。

代码示例 ​

js
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x0b0e14)
const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100)
camera.position.set(4, 3, 5)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
document.getElementById('app').appendChild(renderer.domElement)
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true
controls.target.set(0, 0.6, 0)

// 全局坐标轴与网格：挂在 scene 根上，刻度即世界坐标
scene.add(new THREE.AxesHelper(3))
scene.add(new THREE.GridHelper(8, 16, 0x334155, 0x1e293b))

scene.add(new THREE.AmbientLight(0xffffff, 0.55))
const light = new THREE.DirectionalLight(0xffffff, 1.6)
light.position.set(4, 6, 3)
scene.add(light)

// 在场景树的不同节点上放物体，每个物体再挂自己的小坐标轴（跟随物体）
const entries = [
  { name: '立方体 A', geo: new THREE.BoxGeometry(1, 1, 1),       pos: [2, 0.5, 0],   color: 0x60a5fa },
  { name: '球体 B',   geo: new THREE.SphereGeometry(0.6, 32, 24), pos: [-2, 0.6, -1], color: 0xf472b6 },
  { name: '圆环 C',   geo: new THREE.TorusGeometry(0.5, 0.18, 16, 48), pos: [0, 0.7, 2], color: 0x34d399 }
]
const meshes = entries.map(e => {
  const mesh = new THREE.Mesh(e.geo, new THREE.MeshStandardMaterial({ color: e.color, roughness: 0.4 }))
  mesh.position.set(...e.pos)          // 设置局部（这里父节点是 scene，所以也是世界）坐标
  mesh.add(new THREE.AxesHelper(1.2))  // 子级辅助对象：轴会跟着物体一起动
  scene.add(mesh)
  return { name: e.name, mesh }
})

// 读取世界坐标：getWorldPosition 会沿父链一路累乘
const worldPos = new THREE.Vector3()
renderer.setAnimationLoop(() => {
  meshes.forEach(({ mesh }, i) => { mesh.rotation.y += 0.006 * (i + 1) })
  controls.update()
  renderer.render(scene, camera)

  meshes.forEach(({ name, mesh }) => {
    mesh.getWorldPosition(worldPos)
    // 控制台里可看到每个物体的真实世界坐标
    console.log(name, worldPos.toArray().map(n => n.toFixed(2)))
  })
})

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight
  camera.updateProjectionMatrix()
  renderer.setSize(innerWidth, innerHeight)
})

常见问题解答 ​

Q1：position 设了为什么物体不动？

先确认：① 物体是否已经 add 进场景树；② 是否在每帧里又覆盖了 position（比如动画代码把 y 重置了）；③ 父节点是否有缩放/旋转——子节点的局部坐标要经过父节点变换才是屏幕上看到的位置。

Q2：局部坐标和世界坐标什么时候不一样？

当物体挂在一个自身也有位移/旋转/缩放的父节点下时。例如父 Group 在 (5,0,0)，子 mesh 局部坐标 (1,0,0)，它的世界坐标就是 (6,0,0)。用 getWorldPosition / getWorldQuaternion 读取世界值。

Q3：traverse 是做什么的？

scene.traverse(obj => { ... }) 会深度优先遍历整棵场景树，常用于"批量开关阴影、批量替换材质、统计三角形"。注意它也会遍历到 Light/Camera，处理前用 obj.isMesh 过滤。

动手小练习 ​

  1. 新建一个 Group 放在 (3, 0, 0)，把立方体 A 挂进去并设其局部 position 为 (0,0,0)，用 getWorldPosition 验证它的世界坐标是 (3,0,0)。
  2. 给球体 B 设置 scale.setScalar(1.5)，观察世界坐标读取值是否变化（位置不变、大小变）。
  3. 用 traverse 给场景里所有 Mesh 一次性开启 castShadow。
