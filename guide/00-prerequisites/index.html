0 学前必备：先修知识自查与补课指南 ​

很多人学 Three.js 卡住，不是败在 Three.js 的 API，而是败在前置知识：看不懂 import 语法、分不清弧度和角度、本地双击打开页面一片黑。本章不要求你先成为高手，而是给一张"自查清单 + 补课地图"——每一项都告诉你：需要掌握到什么程度、会在哪里用到、薄弱了先补什么。

Web 基础：一切最终画在 canvas 上 ​

浏览器里画 3D 的唯一入口是 <canvas> 元素加上 WebGL 绘图上下文。Three.js 做的所有事情，最终都会变成对这块画布的像素写入：

html
<!-- 渲染器创建后，把它自带的 canvas 插入页面 -->
<div id="app"></div>
<script type="module">
  document.getElementById('app').appendChild(renderer.domElement)
</script>

另一个必须理解的机制是 importmap——浏览器原生的"模块路径别名"。JavaScript 的裸导入 import * as THREE from 'three' 本来无法被浏览器解析（它不知道 three 指向哪个文件），importmap 告诉浏览器这个路径要从 CDN 哪里取：

html
<script type="importmap">
{
  "imports": {
    "three": "https://cdn.jsdelivr.net/npm/three@0.186.0/build/three.module.js",
    "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.186.0/examples/jsm/"
  }
}
</script>

three/addons/ 带着尾部斜杠，表示"前缀映射"——three/addons/controls/OrbitControls.js 会拼到 examples/jsm/controls/OrbitControls.js。本教程所有演示页都采用这种方式，零构建零安装。

JavaScript：必须顺手的几个语法点 ​

下面的代码浓缩了本教程示例中出现频率最高的语法，如果你每行都能解释清楚，JavaScript 这关就过了：

js
// 解构赋值：从数组/对象里按位置或名字取值
const [x1, y1, d1] = [0.5, 0.3, 4.2]      // 数组解构
const { position, rotation } = mesh        // 对象解构

// 箭头函数 + 默认参数：渲染循环里每帧都会见到
const clamp = (v, min, max) => Math.min(max, Math.max(min, v))

// 模板字符串：拼接提示文本、着色器代码
console.log(`当前像素比 ${renderer.getPixelRatio()}`)

// class 与实例方法：Three.js 的对象体系全部基于类
const v = new THREE.Vector3(1, 0, 0)
v.normalize().multiplyScalar(5)            // 链式调用归一化再放大

// 展开运算符：批量传入参数
camera.position.set(...[3, 2, 4])

// 异步：加载纹理/模型时必然遇到
const texture = await new THREE.TextureLoader().loadAsync('wall.png')

其中异步最容易被忽视：TextureLoader.load 是回调、loadAsync 是 Promise、GLTFLoader 常配 async/await——三种写法要能互相认出来。

3D 数学：Three.js 背后的通用语言 ​

右手坐标系 ​

Three.js 使用右手坐标系：右手四指从 X 轴（右）弯向 Y 轴（上），拇指指向 Z 轴——即 Z 轴朝向观察者（屏幕外）。物体绕某根轴旋转的正方向，遵循"从轴正端向原点看去是逆时针"。

向量：位置与方向的统一抽象 ​

js
const a = new THREE.Vector3(1, 0, 0)
const b = new THREE.Vector3(0, 1, 0)

a.dot(b)             // 点积 = 0：>0 同向、=0 垂直、<0 反向（判断朝向/夹角）
a.clone().cross(b)   // 叉积 = (0,0,1)：同时垂直于 a、b 的法线（算面朝向）
a.distanceTo(b)      // 距离 √2，本质是 |b - a|

点积和叉积是使用频率最高的两个运算：点积用来判断"物体 A 在 B 的前面还是后面"，叉积用来求"这个三角形面朝哪"。

矩阵：所有变换的载体 ​

你设置的 position / rotation / scale 三个属性，每帧都会被合成为一个 4×4 矩阵（模型矩阵）。物体挂在父物体下时，它的世界坐标 = 父矩阵 × 自身矩阵 连乘——这就是 2.2 进阶篇讲的层级变换。一帧画面中坐标要经历三次变换：

欧拉角、四元数与弧度 ​

  • 欧拉角（mesh.rotation）：按 X/Y/Z 三个角度旋转，直观但存在"万向锁"问题（特定角度下丢失一个自由度）。
  • 四元数（mesh.quaternion）：用 4 个数描述旋转，插值平滑、无万向锁，动画与相机控制内部都用它。两者改一个会自动同步另一个。
  • 弧度：Three.js 所有角度参数都是弧度。记住 180° = Math.PI，换算用 deg * Math.PI / 180。1.1 示例里 rotation.x += 0.01 意味着每帧转约 0.57°。

渲染常识：三角形、管线与 PBR ​

  1. 一切 3D 形状都是三角形拼的——一个 BoxGeometry 由 12 个三角形组成，一个精细球体可能上万。模型面数直接决定渲染开销，这是第 11 章性能优化的基础。
  2. 渲染管线三步：
    • 顶点着色器：把每个顶点乘以模型/视图/投影矩阵，得到屏幕位置；
    • 光栅化：把三角形覆盖的区域拆成一个个像素；
    • 片元着色器：逐像素计算最终颜色（贴图采样、光照计算都在这里）。
  3. PBR（基于物理的渲染）一句话：MeshStandardMaterial 用"金属度 + 粗糙度"描述表面对光的反射方式，因此必须配合灯光才能看到东西——这也解释了 1.1 FAQ 里"黑屏三坑"之一。

运行环境：静态服务器、CORS 与依赖管理 ​

为什么双击打开 html 会报错？ ES Module 出于安全策略要求页面运行在 http(s):// 协议下。file:// 协议直接打开会被 CORS 拦截，报类似 "Access to script ... has been blocked by CORS policy" 的错误。解决办法是起一个本地静态服务器，任选其一：

bash
# 方式一：Node 生态的零配置静态服务器（推荐）
npx serve .

# 方式二：VSCode 插件 Live Server，右键 html → Open with Live Server

# 方式三：本教程仓库本身就是 VitePress 项目，直接
pnpm dev

代码示例 ​

示例一：向量的点积与叉积（Three.js 形态） ​

用 10 行代码体会"数学直接变成 API"：

js
// 场景：判断敌人是否在我前方 60° 视野内（点积的典型应用）
const myForward = new THREE.Vector3(0, 0, -1)  // 我面朝 -Z（Three.js 相机默认朝向）
const toEnemy = new THREE.Vector3(3, 0, -4).normalize()  // 指向敌人的单位向量

const facing = myForward.dot(toEnemy)          // 夹角余弦值 ∈ [-1, 1]
const angle = Math.acos(facing) * 180 / Math.PI  // 反解出角度 ≈ 36.9°
const inSight = angle < 60                     // true → 在视野内

// 场景：求地面的法线（叉积的典型应用）
const p1 = new THREE.Vector3(0, 0, 0)
const p2 = new THREE.Vector3(1, 0, 0)
const p3 = new THREE.Vector3(0, 0, -1)
const normal = new THREE.Vector3()
  .subVectors(p2, p1)
  .cross(new THREE.Vector3().subVectors(p3, p1))
  .normalize()                                 // (0, 1, 0)：法线朝上

示例二：不用 Three.js，手写透视投影立方体 ​

下面这段代码零依赖，只用原生 Canvas 2D，把 Three.js 在幕后替你做的事全部摊开：顶点表 → 旋转矩阵 → 透视除法 → 画线。看懂它，后面学相机和几何体就是"给已知概念起名字"。

html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <title>手写透视投影</title>
</head>
<body>
  <canvas id="stage"></canvas>
  <script>
    const canvas = document.getElementById('stage')
    const ctx = canvas.getContext('2d')
    canvas.width = 600; canvas.height = 400
    const cw = 600, ch = 400

    // ---------- 1. 模型：8 个顶点 + 12 条边（模型局部坐标） ----------
    const S = 1.1  // 半边长
    const VERTICES = [
      [-S,-S,-S], [ S,-S,-S], [ S, S,-S], [-S, S,-S],
      [-S,-S, S], [ S,-S, S], [ S, S, S], [-S, S, S],
    ]
    const EDGES = [
      [0,1],[1,2],[2,3],[3,0], [4,5],[5,6],[6,7],[7,4], [0,4],[1,5],[2,6],[3,7],
    ]

    // ---------- 2. 旋转矩阵：先绕 X 再绕 Y（R = Ry · Rx） ----------
    // 这就是 Three.js 里 mesh.rotation 每帧背后发生的事
    function rotate([x, y, z], ax, ay) {
      const cx = Math.cos(ax), sx = Math.sin(ax)
      const cy = Math.cos(ay), sy = Math.sin(ay)
      const y1 = y * cx - z * sx    // 绕 X 轴：y/z 平面内旋转
      const z1 = y * sx + z * cx
      const x2 = x * cy + z1 * sy   // 绕 Y 轴：x/z 平面内旋转
      const z2 = -x * sy + z1 * cy
      return [x2, y1, z2]
    }

    // ---------- 3. 透视投影：3D 点 → 2D 像素 ----------
    // fov=60°、相机在 (0,0,cameraDistance) 看向原点
    const FOV = 60, DIST = 4
    function project([x, y, z]) {
      const depth = z + DIST                          // 把物体推到相机前方
      const f = 1 / Math.tan((FOV * Math.PI) / 360)   // 半视场角求焦距
      const scale = (f / depth) * (ch / 2)            // 透视除法：越远越小
      return [cw / 2 + x * scale, ch / 2 - y * scale] // 屏幕中心为原点
    }

    // ---------- 4. 画一帧 ----------
    const rx = -0.42, ry = 0.66  // 旋转角（弧度）
    const pts = VERTICES.map(v => project(rotate(v, rx, ry)))
    ctx.strokeStyle = '#7cc4ff'; ctx.lineWidth = 2
    for (const [a, b] of EDGES) {
      ctx.beginPath(); ctx.moveTo(...pts[a]); ctx.lineTo(...pts[b]); ctx.stroke()
    }
  </script>
</body>
</html>

关键就三件事：rotate() 是矩阵变换，f / depth 是透视除法（近大远小的全部来源），cw/2 - y*scale 里的负号是因为屏幕 Y 轴向下而 3D Y 轴向上。

常见问题解答 ​

Q1：完全不会 JavaScript，能直接学 Three.js 吗？

不建议。Three.js 每个示例都是十几行起跳的 JS 代码，语法关过不了会同时应付"语言 + 图形 API + 数学"三座山。建议先花 1–2 周完成本文自查清单中「JavaScript 语法」和「异步编程」两行的补课内容，再回来从 1.1 开始。

Q2：需要先系统啃完线性代数课程吗？

不需要。三维图形只用到线性代数的一个很小子集（向量点积/叉积、4×4 矩阵、四元数），而且是"用到哪个讲哪个"：本页讲清概念直觉，2.2 进阶篇展开层级矩阵的实际运算。遇到陌生术语现场查即可，不必先修完一整门课。

Q3：本地双击打开 html 黑屏/控制台报 CORS 错误？

file:// 协议下浏览器会拦截 ES Module 与跨源资源，这是安全策略而非 bug。用「运行环境」小节里的任一方式起本地静态服务器（npx serve . 最快），通过 http://localhost:3000 访问即可。

Q4：CDN 和 npm 两种引入方式会冲突吗？该用哪个？

不会冲突，import 语句完全一样，区别只由 importmap 或打包工具解析。学习阶段用 CDN（零安装、随开随写）；做正式项目用 npm（类型提示、摇树优化、版本锁定）。从 CDN 迁到 npm 只需删掉 importmap、装上 three 包。

Q5：需要先学 WebGL 或 GLSL 着色器吗？

不需要。Three.js 正是为"不想手写着色器"的人设计的，本教程全部内容只涉及高层 API。只有当你要写自定义 ShaderMaterial 时才需要 GLSL，那已经超出本教程范围，可参考 Three.js 官方仓库的 shader 示例进阶。

Q6：学到一半发现某段代码看不懂，怎么定位是哪块前置缺失？

回到本页第一张自查表：看不懂 import → 「ES Module」；看不懂 =>、...、${} → 「JavaScript 语法」；看不懂 .then / await → 「异步编程」；看不懂 rotation 为什么用弧度、物体为什么转反 → 「3D 数学」；看不懂为什么材质是黑的 → 「渲染常识」。每行都给出了补课入口。

动手小练习 ​

  1. 手算点积：(1,0,0) · (0.707,0.707,0) ≈ 0.707，再用 Math.acos 反解角度（答案：约 45°）。然后到上方「向量实验室」把 B 拖到与 A 成 45°，看数值是否与手算一致。
  2. 打开本页演示的「在线编辑」，把 FOV 从 60 改成 110，观察广角下的边缘拉伸畸变——这就是 fov 参数的直观含义。
  3. 用 npx serve . 在本地跑通 1.1 的 hello-cube，然后故意双击 html 文件用 file:// 打开，读一遍控制台的 CORS 报错并说出原因。
  4. 用 new THREE.Vector3() 验证叉积 (1,0,0) × (0,1,0) = (0,0,1)；再到 3D 实验室把 A、B 摆到同样方向，确认紫色叉积箭头指向 +Z（右手定则），把 B 换成 -Y 方向再看它如何翻转。
