Three.js 系统教程（VitePress） ​

一套由浅入深、模块分阶段、带在线可运行演示的 Three.js 中文教程。基于 Three.js r186 与 VitePress 构建，无需后端、演示零构建（CDN importmap 直跑）。

  • 11 大模块 × 3 阶段 = 33 篇章节
  • 33 个可独立运行、可在线编辑（CodeSandbox）的 Three.js 演示
  • 全文中文搜索、侧边栏 + 面包屑导航、响应式布局、学习路径建议
  • 🎬 漫画剧场：12 话霓虹墨四格漫画（含 EP.00 学前预备，SVG 原画 + 讲解 + 自测），见 comics/README.md，本地起服务后访问 /comics/index.html 一键阅读

技术栈 ​

依赖版本作用
three（CDN 运行时）0.186.0演示页通过 jsDelivr importmap 加载
vitepress^1.5.0文档站点框架（基于 Vite + Vue 3）
vue^3.5.13自定义演示框 / 流程图 / 面包屑组件

本地开发 ​

bash
# 1. 安装依赖（仅 VitePress 与 Vue，体积很小）
npm install

# 2. 启动开发服务器（默认 http://localhost:5173）
npm run docs:dev

# 3. 构建生产静态站点，产物在 .vitepress/dist
npm run docs:build

# 4. 本地预览构建产物（验证部署前效果）
npm run docs:preview

演示页位于 public/demos/，是完全自包含的静态 HTML。本地用任意静态服务器打开也能直接运行（需要联网访问 CDN）。

在线编辑演示 ​

每个演示右上角提供：

  • 在 CodeSandbox 中打开：基于 CodeSandbox define API（https://codesandbox.io/api/v1/sandboxes/define，template=static），一键把当前演示源码发布成静态沙箱并打开在线 IDE
  • 复制源码：复制完整 HTML 到本地
  • 新窗口打开：脱离 iframe 全屏体验

部署 ​

npm run docs:build 的产物在 .vitepress/dist，是纯静态文件，可托管到任意静态平台。

① GitHub Pages（私有源码 + 公开部署仓） ​

线上站点：https://yzhijie.github.io/threejs-tutorial-site/

本仓库为私有源码仓，.github/workflows/deploy.yml 在每次 push 到 main 后自动构建，并把产物推送到公开部署仓 YZhiJie/threejs-tutorial-site 的 gh-pages 分支，由 GitHub Pages 对外提供服务。

因此 .vitepress/config.mts 中的 base 固定为部署仓名：

ts
export default defineConfig({
  base: "/threejs-tutorial-site/",
  // ...其余配置
})

如果改用根站点（<用户名>.github.io），则不要设置 base（保持 /）。

② Netlify ​

  • Build command：npm run docs:build
  • Publish directory：.vitepress/dist
  • Node 版本建议 18+（在环境变量或 .nvmrc 指定）

或使用配置文件 netlify.toml：

toml
[build]
  command = "npm run docs:build"
  publish = ".vitepress/dist"

③ Vercel ​

  • Framework Preset：VitePress（若无则选 Other）
  • Build Command：npm run docs:build
  • Output Directory：.vitepress/dist
  • 根路径部署无需改 base；若部署到子路径，同样需要在 config 里设置对应 base。

④ Nginx（自托管） ​

构建后把 dist 目录放到站点根，示例配置：

nginx
server {
    listen 80;
    server_name three.example.com;
    root /var/www/threejs-tutorial/.vitepress/dist;
    index index.html;

    # cleanUrls 已开启，下面的 try_files 兜底处理前端路由与目录索引
    location / {
        try_files $uri $uri.html $uri/ =404;
    }
}

若部署在子路径（如 https://example.com/three/），需同时设置 config 的 base: '/three/' 与 Nginx 的 location /three/。

关于 CDN 与离线 ​

演示通过 https://cdn.jsdelivr.net/npm/three@0.186.0/... 加载 Three.js，运行环境需能访问外网。如需完全离线：把 build/three.module.js 与 examples/jsm/ 下载到 public/vendor/three/，并批量修改各演示 importmap 的路径即可。
