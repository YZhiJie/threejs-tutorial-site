等价的 Vue 3 + TresJS 写法

WebGL2 · 全量能力 
<!-- 静态对照：演示页不加载 Vue / TresJS -->
<script setup>
import { reactive } from 'vue'
import { TresCanvas } from '@tresjs/core'

const scene = reactive({
  color: '#22d3ee',
  spin: 0.8,
  angle: 0,
})
</script>

<template>
  <TresCanvas :dpr="[1, 2]"
             clear-color="#0b0e14">
    <TresPerspectiveCamera
      :position="[2.4, 1.8, 3.2]" />
    <TresDirectionalLight
      :position="[3, 5, 2]" />

    <TresMesh :rotation-y="scene.angle">
      <TresTorusKnotGeometry
        :args="[0.75, 0.24, 180, 32]" />
      <!-- 改 color 值，场景自动换色 -->
      <TresMeshStandardMaterial
        :color="scene.color" />
    </TresMesh>
  </TresCanvas>
</template>

右 · reactive.color'#22d3ee'
右 · reactive.spin0.80
右 · 更新时机框架比对后赋值
目标端配置DPR≤2 · 阴影开 · 段数 180
Web：Vue 自定义渲染器直接操作 WebGL2，TresJS 模板可以全量使用；下方滑块改的是同一份响应式数据。
