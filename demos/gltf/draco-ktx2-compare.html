本地压缩命令

npm i -g @gltf-transform/cli gltf-transform draco in.glb out.glb gltf-transform webp in.glb out.glb gltf-transform etc1s in.glb out.glb # 需装 KTX-Software gltfpack -i in.glb -o out.glb -cc -tc # meshopt 路线

装配代码（本页真实使用）

const draco = new DRACOLoader() .setDecoderPath('…/libs/draco/') const ktx2 = new KTX2Loader() .setTranscoderPath('…/libs/basis/') .detectSupport(renderer) // 必须！ loader.setDRACOLoader(draco) loader.setKTX2Loader(ktx2) 当前 Flamingo.glb 未压缩（77 KB，直接可读）；遇到带 KHR_draco_mesh_compression / KHR_texture_basisu 扩展的模型时，上面装配的解码器会自动接管。
